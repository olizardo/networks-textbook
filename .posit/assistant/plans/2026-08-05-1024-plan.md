# Plan: Compare Topics with Hanneman & Riddle's Textbook

## Overview
The user requested a comparison between the current textbook project and Hanneman & Riddle's "Introduction to social network methods" (https://faculty.ucr.edu/~hanneman/nettext/) to identify topics covered in Hanneman but missing from the current project.

## Findings
Based on the table of contents of Hanneman & Riddle and the `_quarto.yml` of the current project, the current project already covers many fundamental areas (graphs, matrices, centrality, ego networks, two-mode networks, cliques, structural equivalence). 

However, the following topics are present in Hanneman & Riddle but are **not** explicitly covered in the current textbook's table of contents:

1. **Multiplex Networks** (Hanneman Chapter 16)
   - Networks with multiple types of relations or ties between the same set of actors.
2. **Automorphic Equivalence** (Hanneman Chapter 14)
   - A deeper structural equivalence concept where actors are indistinguishable based on the graph's structure, even if their specific neighbors differ.
3. **Regular Equivalence** (Hanneman Chapter 15)
   - Equivalence based on actors having similar relationships to other *types* of actors, rather than to the exact same actors (role equivalence).
4. **Statistical Tools for Networks** (Hanneman Chapter 18)
   - Inferential statistics applied to network data (e.g., QAP - Quadratic Assignment Procedure, ERGMs - Exponential Random Graph Models).
5. **Specific Software Tutorials** (Hanneman Chapters 4 & 6)
   - Hanneman focuses heavily on UCINET and NetDraw. While the current text uses R (which is preferable here), there might be room for a dedicated "Working with Network Data in R" chapter if data wrangling isn't fully covered elsewhere.
