# Plan: Fixing Visual Obscurations in Network Growth Diagrams (`slides/ties-motifs.qmd`)

This plan addresses the issue of network growth diagrams (`gr_g1`, `gr_g2`, `gr_g3`) where edges (especially undirected sibling or marriage ties) overlap or obscure the node points and their labels, leading to a cluttered presentation.

---

## 1. Visual Bug Diagnosis

In the network growth diagrams, the R chunks map multiple types of ties (parent-child, sibling, romantic, marriage, in-law, baby) simultaneously.
* **The Obscuration Issue**: Because `gr_g1`, `gr_g2`, and `gr_g3` are set up as `directed = TRUE` graphs (so arrows can be drawn for parent and romantic ties), `ggraph`'s `geom_edge_parallel` draws *all* edges using the parallel/arc geom with an arrow parameter. For non-directed ties (like sibling and marriage), we suppress the arrow by passing custom scales, but the edges still run all the way into the center of the node points, drawing right over the `"You"` and `"Riley"` text labels.
* **The Fix**: We need to formally separate the drawing of *directed* edges (which get arrowheads) from *undirected* edges (which should just be simple straight lines without arrowheads that obey node boundaries properly).

---

## 2. Implementing the Fix via Edge Filtering

We will split the edge rendering in `gr_g1`, `gr_g2`, and `gr_g3` into two separate `geom_edge_*` calls using `aes(filter = ...)`:

### For Directed Ties (Parent, Romantic, Baby, In-Law)
```r
geom_edge_parallel(
  aes(filter = type %in% c("parent", "romantic", "inlaw", "baby"), color = type, linetype = type),
  arrow = arrow(length = unit(3.5, 'mm'), type = "closed"),
  start_cap = circle(10, 'mm'), end_cap = circle(10, 'mm'),
  sep = unit(4, 'mm'), edge_width = 1.25
)
```

### For Undirected Ties (Sibling, Marriage)
Instead of using parallel arcs, we will use standard `geom_edge_link` for undirected ties. `geom_edge_link` natively respects node caps better and draws straight, clean lines:
```r
geom_edge_link(
  aes(filter = type %in% c("sibling", "marriage"), color = type, linetype = type),
  start_cap = circle(10, 'mm'), end_cap = circle(10, 'mm'),
  edge_width = 1.25
)
```

This strict separation ensures that:
1. Sibling and marriage lines stop perfectly at the 10mm radius of the node circle.
2. Parent, in-law, and baby arrows stop perfectly at the 10mm radius with their arrowheads intact.
3. No edge will ever cross into the center of the node or obscure the white text labels.

---

## 3. Applying the Fix

We will apply this two-geom filter strategy to the three network growth chunks:
- `## Two Separate Family Systems` (Chunk 5)
- `## The Merged Family Network` (Chunk 6)
- `## The Consolidated Kinship Network` (Chunk 7)

We will then re-render `slides/ties-motifs.qmd` to verify that all nodes and text labels are 100% visible and unobscured.
