# Plan: Fix Asymmetric and Anti-Symmetric Tie Visualizations Once and For All

This plan outlines the definitive solution to the stretching, squishing, and label misalignment issues in the 2-node tie visualizations (`lesson-graphs-ties.qmd` and `slides/ties-motifs.qmd`).

---

## 1. The Root Cause: Aspect Ratio Distortion (`coord_cartesian`)

When using `coord_cartesian()` with tight vertical limits (`ylim = c(0.82, 1.18)` or `ylim = c(0.7, 1.3)`), ggplot is forced to stretch the vertical units of the data coordinate system to fit the physical height of the output device (Reveal.js slides or PDF/HTML pages).

Because slides are extremely wide (16:9), this vertical stretching magnifies the height of the plot relative to its width. This leads to several major visual bugs:
1. **Elongated Nodes**: Perfect node circles are stretched into tall, thin vertical ellipses.
2. **Exaggerated Curves**: Arc curves with tiny strengths (like `0.06` or `0.1`) are magnified into massive loops.
3. **Floating Labels**: The red `"✕"` and the `"?"` drift far away from the curves.
4. **Clipped Arrowheads**: Arrowheads clip through the sides of the elongated node ellipses because the grid engine draws circular end caps while the node points are drawn as ellipses.

---

## 2. The Definitive Solution: `coord_fixed`

We will replace `coord_cartesian()` with **`coord_fixed()`** (or `coord_equal()`) in the `plot_tie_type` function across both files:
```r
coord_fixed(ratio = 1, xlim = c(0.6, 2.4), ylim = c(0.65, 1.35), clip = "off")
```

### Why `coord_fixed` solves the problem:
1. **Perfect Circles**: Forces the aspect ratio of the data coordinates to be exactly 1:1 on any screen or device. Node points are guaranteed to remain **perfect, beautiful circles** under any display resolution.
2. **Consistent Proportions**: The curved arcs and arrowheads will have their natural, designed proportions.
3. **Perfect Alignment**: The red `"✕"` and other labels will align exactly on top of the curved arcs, as their mathematical midpoints are locked in 1:1 space.

### Step 3.3: `plot_tie_type` Function
We will update `plot_tie_type` to use `coord_fixed` and place the red `"✕"` exactly at $y = 0.90$ (which is the peak of the downward red dashed curve of strength 0.1):
```r
plot_tie_type <- function(nodes, edges, title, subtitle, directed = TRUE, has_cross = FALSE) {
  g <- tbl_graph(nodes = nodes, edges = edges)
  p <- ggraph(g, layout = "manual", x = x, y = y)
  
  if (directed) {
    p <- p + geom_edge_arc(aes(strength = strength, color = color, linetype = linetype),
                           arrow = arrow(length = unit(4, 'mm'), type = "closed"),
                           end_cap = circle(8, 'mm'),
                           start_cap = circle(8, 'mm'),
                           width = 1.1,
                           show.legend = FALSE) +
             scale_edge_color_identity() +
             scale_edge_linetype_identity()
  } else {
    p <- p + geom_edge_link(color = "#2c3e50",
                            width = 1.1,
                            end_cap = circle(8, 'mm'),
                            start_cap = circle(8, 'mm'),
                            show.legend = FALSE)
  }
  
  # Standardize nodes
  p <- p + geom_node_point(size = 14, fill = "#ecf0f1", color = "#2c3e50", shape = 21, stroke = 1.5) +
    geom_node_text(aes(label = name), size = 5, fontface = "bold", color = "#2c3e50")
  
  # Red cross annotated exactly at y = 0.90
  if (has_cross) {
    p <- p + annotate("text", x = 1.5, y = 0.90, label = "✕", color = "#e74c3c", size = 8, fontface = "bold")
  }
  
  p <- p + 
    labs(title = title, subtitle = subtitle) +
    theme_graph() +
    theme(
      plot.title = element_text(size = 12, face = "bold", color = "#2c3e50", hjust = 0.5),
      plot.subtitle = element_text(size = 9.5, color = "#7f8c8d", hjust = 0.5, lineheight = 1.1),
      plot.margin = margin(10, 10, 10, 10)
    ) +
    coord_fixed(ratio = 1, xlim = c(0.6, 2.4), ylim = c(0.65, 1.35), clip = "off")
  
  return(p)
}
```
