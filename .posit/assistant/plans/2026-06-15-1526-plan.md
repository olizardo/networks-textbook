2. **`## What is a Tree Graph?`** (Theoretical slide with visual):
   - Define a **tree graph**: Any graph that is both **connected** and **acyclic** (has no cycles).
   - Right side: Plot a beautiful 5-node undirected tree graph.
3. **`## Properties of Tree Graphs`**:
   - Explain the "One Cycle Property": adding any single edge to a tree always creates exactly one cycle, destroying its tree status.
   - Explain the "Single Path Property": there exists exactly *one* unique path connecting any pair of nodes.
4. **`## Tree Graph Metrics: Vertices & Edges`**:
   - The fundamental edge-node relationship:
     $$m = n - 1 \qquad \text{or} \qquad n = m + 1$$
   - Sum of degrees identity:
     $$\sum_i k_i = 2(n-1) = 2n - 2$$
5. **`## Tree Graph Density & Average Degree`**:
   - Show how the edge constraint simplifies global metrics:
     - **Density**: $d(T) = \frac{2}{n}$ (compared to $\frac{2m}{n(n-1)}$).
     - **Average Degree**: $\bar{k} = \frac{2n-2}{n}$.
6. **`## Trees as Minimally Connected Graphs`**:
   - Define **minimal connectivity** (connected using the smallest possible number of edges).
   - **Bridges rule**: Removing *even a single edge* disconnects a tree. Thus, **every edge in a tree graph is a bridge**!
7. **`## Forests`** (Two-column, before-and-after plot):
   - Define a **forest**: A disconnected graph whose components are all trees.
   - Left: A connected 6-node tree graph.
   - Right: A disconnected 6-node forest after removing one edge, split into two components.
8. **`## Special Types of Trees: Line and Star Graphs`** (R Plot):
   - Introduce **The Line Graph ($L_n$)**: A single long path of nodes (modeling the "Telephone Game").
   - Introduce **The Star Graph ($S_n$)**: A central hub connected to $n-1$ leaf nodes (extreme centralization).
   - Plot both side-by-side using `patchwork`.
