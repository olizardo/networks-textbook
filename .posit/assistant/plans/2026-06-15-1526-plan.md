### Step 1.3: Re-layout Edge-Deleted Subgraphs to Before/After
On the slide `## Edge-Deleted Subgraphs: Example` (Line 787):
* **Before Plot (`p_before`)**:
  - Highlights the 6 deleted edges $\{AB, GJ, CI, AE, AC, CE\}$ in red:
    ```r
    p_before <- gr |>
      activate(edges) |>
      mutate(
        from_name = .N()$name[from],
        to_name = .N()$name[to],
        highlight = ifelse(
          (from_name == "A" & to_name == "B") | (from_name == "B" & to_name == "A") |
          (from_name == "G" & to_name == "J") | (from_name == "J" & to_name == "G") |
          (from_name == "C" & to_name == "I") | (from_name == "I" & to_name == "C") |
          (from_name == "A" & to_name == "E") | (from_name == "E" & to_name == "A") |
          (from_name == "A" & to_name == "C") | (from_name == "C" & to_name == "A") |
          (from_name == "C" & to_name == "E") | (from_name == "E" & to_name == "C"),
          "yes", "no"
        )
      ) |>
      ggraph(layout = l) +
      geom_edge_link(aes(color = highlight, edge_width = highlight)) +
      scale_edge_color_manual(values = c("yes" = "red", "no" = "steelblue"), guide = "none") +
      scale_edge_width_manual(values = c("yes" = 2.0, "no" = 1.0), guide = "none") +
      geom_node_point(size = 14, color = "tan2") +
      geom_node_text(aes(label = name), size = 6, fontface = "bold", color = "white") +
      theme_graph() + ggtitle("Before (Deleting Red Edges)") + coord_cartesian(clip = "off") +
      theme(plot.title = element_text(size = 11, face = "bold", hjust = 0.5))
    ```
* **After Plot (`p_after`)**:
  - The resulting edge-deleted subgraph `gr4` (with those edges removed).
* **Layout**: Combined as `p_before + p_after` (fig-width 8, fig-height 4.5), with text column at `width="40%"` and figure column at `width="60%"`.
