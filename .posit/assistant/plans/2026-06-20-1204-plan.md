# Plan: Audit Slide Files for Terminology Inconsistencies

This plan outlines the approach to systematically audit all textbook slide decks (`slides/*.qmd`) and their corresponding chapter lessons (`lesson-*.qmd`) for discrepancies, errors, or stylistic variances in network analysis and graph theory terminology.

## 1. Initial Key Findings

Based on our initial read-only exploration of the workspace, we have already identified several key terminological and notation discrepancies that need alignment:

1. **"Tertius Lungens" vs. "Tertius Iungens" (Spelling Error):**
   * **Inconsistency:** In `slides/structural-holes.qmd` (line 697) and `lesson-theory-sht.qmd`, the Obstfeld (2005) strategic orientation of "Tertius Iungens" (Latin for "the third who joins") is misspelled as **"Tertius Lungens"** (with an 'L').
   * **Fix:** Correct all instances in both slides and lessons to the standard **"Tertius Iungens"** (or "Tertius Jungens" if preferred, but "Iungens" is most standard).

2. **Clustering Coefficient Notation Variance:**
   * **Inconsistency:** In `slides/small-world.qmd` (line 44), the local clustering coefficient is defined as:
     $$CC_i = \frac{m}{n(n-1)/2}$$
     While in `slides/ego-metrics.qmd` (line 72), it is defined as:
     $$CC_i = \frac{2m}{n(n-1)}$$
   * **Impact:** Although mathematically identical, using two different symbolic arrangements for the exact same metric creates unnecessary cognitive friction for students.
   * **Fix:** Standardize on one format (e.g., $CC_i = \frac{2m}{n(n-1)}$) across both decks.

3. **"Closed Trail" vs. "Cycle" (Subtle Technical Discrepancy):**
   * **Inconsistency:** In `lesson-graphs-paths.qmd` (line 144), it states: *"Note that a closed trail is the same as a cycle."*
   * **Impact:** Strictly in graph theory, a cycle is a closed **path** (meaning no vertices can be repeated, except the start/end). A closed **trail** (often called a circuit) is forbidden from repeating edges but *can* repeat intermediate vertices (e.g., $A \rightarrow B \rightarrow C \rightarrow D \rightarrow B \rightarrow E \rightarrow A$ is a closed trail but not a cycle).
   * **Fix:** Clarify this distinction or refine the wording so that it is pedagogically precise and mathematically correct, and ensure the slides are aligned.
