# Plan: Fix Karma Theory figures to show out-valence → in-valence correspondence, not dyadic reciprocity

## Problem

Karma Theory predicts a **node-level correspondence**: the valence of the ties you send out predicts the valence of the ties you receive back **from the network at large** — not that the same alters return your ties. Per Omar, the existing **"Karma Theory: Network-Wide Flow"** figure is the right pattern (spreader sends to one set of alters, receives from a *different* set). Two other Part 1 figures currently draw direct dyadic reciprocity, which misrepresents the concept:

1. **"Karma Theory: Core Concept"** — two mutual dyads (You ↔ Frnd green; You ↔ Bly red dashed). This is literally reciprocity, the wrong mechanism.
2. **"Karma Dynamics: Virtuous vs. Vicious Cycles"** — two nodes (A ↔ B, C ↔ D) each with parallel edges labeled "Acts Nice / Reciprocates / Lunch / Support". Same reciprocity problem.

## Changes (all in `slides/valenced-interactions.qmd`, Part 1 only)

### 1. Core Concept slide — redraw the figure using the Network-Wide Flow pattern
Replace the two mutual-dyad panels with two small generalized-flow panels (patchwork, same 2-panel layout and `fig.width: 6 / fig.height: 5`):

- **"Likers Get Liked" panel**: focal node "You" (green fill, as now) sends two positive arrows to alters X, Y on one side and receives two positive arrows from *different* alters W, Z on the other side. No alter appears on both sides, so no dyad is reciprocal.
- **"Bullies Get Bullied" panel**: identical structure with red dashed negative arrows.
- Small enough node count (5 per panel) that the figure stays readable at the current slide geometry.

### 2. Core Concept slide — fix the bullet wording
Current bullet says "individuals tend to **reciprocate** the sentiments that others broadcast to the network." Revise to state the correspondence explicitly, e.g.:

- "The **valence you send out** predicts the valence you get back — from the network at large, not necessarily from the same alter."
- Keep the "Likers get liked / Bullies get bullied" expressions (they match the chapter).

### 3. Virtuous/Vicious Cycles slide — replace the two-node multi-edge dyads entirely
The current panels stack four parallel arrows between just two nodes (A ↔ B, C ↔ D) — a single dyad drawn as multiple lines, which is both visually odd and conceptually wrong (a dyad can hold at most one tie per direction, and the picture reads as pure reciprocity). Replace each panel with a small generalized-flow network of uniform sign, in the Network-Wide Flow style:

- **Virtuous Cycle**: focal node A (green) sends one positive arrow to each of two alters and receives one positive arrow from each of two *different* alters. Exactly one line per directed tie, no reciprocated dyads.
- **Vicious Cycle**: focal node C (red) sends one negative dashed arrow to each of two alters and receives one negative dashed arrow from each of two different alters.
- Drop the per-edge type labels/colors entirely (the panels are already legend-less after the earlier QA pass).

### 4. Virtuous/Vicious Cycles slide — fix the bullet wording
- "breeds positive reciprocity ($+$)" → "breeds matching positive sentiment from others ($+$) — not necessarily from the same alter".
- Mirror the clarification once in the vicious bullet ("hostile counter-attacks" wording can stay).

### 5. Network-Wide Flow slide — keep the figure; add one clarifying line
Add a short final bullet: "Note that no alter returns A's or B's tie directly; the match is between what each node sends and what it receives from others." This makes the key contrast explicit and ties the three karma slides together.
