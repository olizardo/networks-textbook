12  Directed Graphs

12.1 Introduction to Directed Graphs (Digraphs)

While simple undirected graphs are useful for representing symmetric relationships (where connection is naturally mutual), many social relationships are inherently directional (see Chapter 5). In these relationships, one member of a pair can claim a tie with the other, but the other person may or may not send the same tie back. Examples include giving advice, sending emails, lending money, or nominating friends.

To represent directional relations, we use directed graphs (also called digraphs). In a directed graph, the edges are ordered pairs of nodes, meaning the order in which we list the nodes in an edge matters. The connection goes from a source node (the sender) to a destination node (the receiver). Therefore, the edge \(AB\) is a different entity from the edge \(BA\).

In directed graphs, simple undirected lines are replaced by directed arrows (often called arcs). When a digraph has no loops (edges connecting a node to itself) and at most one directed edge connecting a sender to a receiver in each direction, it is called a simple directed graph.

Figure 12.1 shows a point-and-line diagram of a digraph representing a simple directed social network.

In directed networks, reciprocity is a major analytical focus. For some ties (such as liking, trusting, or friendship), reciprocity is binary; it either exists or it does not. If Figure 12.1 were an advice network (Cross et al. 2001), we could say that H seeks advice from D, but D does not seek advice from H. This lack of reciprocity is common in formal hierarchies, where advice-seeking often flows upward to more experienced or authoritative actors, reflecting power differentials.

12.2 Node Neighborhoods in Directed Graphs

Just like in undirected (simple) graphs, each node in a directed graph has a node neighborhood. However, because each node can be the source or destination for an asymmetric edge, we have to differentiate the neighborhood of a node depending on whether the node is the sender or the recipient of a given link.

12.2.1 In-Neighborhoods

We say that a node j is an in-neighbor of a node i if there is a directed link with j as the source and i as the destination node (\(j \rightarrow i\)). For each node, the full set of in-neighbors forms the in-neighborhood of that node. This is written:

\[ N^{in}(v) \]

where \(v\) is the label corresponding to the node. For instance, in Figure 12.1, the node set \(N^{in}(D) = \{B, E, G\}\) is the in-neighborhood of node D.

12.2.2 Out-Neighborhoods

In the same way, we say that a node i is an out-neighbor of a node j if there is a directed link with j as the source and i as the destination (\(j \rightarrow i\)). For each node, the full set of out-neighbors defines the out-neighborhood of that node. This is written:

\[ N^{out}(v) \]

where \(v\) is the label corresponding to the node. For instance, in Figure 12.1, the node set \(N^{out}(B) = \{A, C, D\}\) is the out-neighborhood of node B.

Nodes will only appear in both the in- and out-neighborhood sets when there are reciprocal or mutual ties between the nodes. For instance, in Figure 12.1, the out-neighborhood of node F is \(\{A\}\) and the in-neighborhood is \(\{A, G\}\). Here, node A appears in both the in- and out-neighborhood sets because A has a reciprocal tie with F.

12.2.3 Neighborhood Intersection in Directed Graphs

Just as in the undirected case, the sets of neighbors for any two nodes in a directed graph can share members in common. However, because directed neighborhoods are differentiated by directionality, we can examine two types of intersection.

In-Neighborhood Intersection (\(N^{in}(u) \cap N^{in}(v)\)): Represents the set of common “nominators” or senders—nodes that direct an edge to both \(u\) and \(v\). In a social network, a high in-neighborhood intersection suggests that \(u\) and \(v\) share similar sources of prestige, influence, or advice.

Out-Neighborhood Intersection (\(N^{out}(u) \cap N^{out}(v)\)): Represents the set of common targets—nodes that both \(u\) and \(v\) direct an edge to. In a social network, this indicates shared sociability targets (e.g., \(u\) and \(v\) both sending advice to the same set of people).

Let’s find these two types of intersections for nodes \(C\) and \(D\) in Figure 12.1:

For In-Neighborhoods: \(N^{in}(C) = \{B, E\}\) and \(N^{in}(D) = \{B, E, G\}\). The intersection is: \[ N^{in}(C) \cap N^{in}(D) = \{B, E\} \]

This means both \(C\) and \(D\) receive incoming connections from nodes \(B\) and \(E\).

For Out-Neighborhoods: \(N^{out}(C) = \emptyset\) and \(N^{out}(D) = \{B\}\). The intersection is: \[ N^{out}(C) \cap N^{out}(D) = \emptyset \]

Since node \(C\) sends no outgoing ties, there is no overlap in their outgoing targets. If we instead intersect \(E\) and \(G\) (where \(N^{out}(E) = \{C, D\}\) and \(N^{out}(G) = \{F, D\}\)), we find: \[ N^{out}(E) \cap N^{out}(G) = \{D\} \]

This shows that both \(E\) and \(G\) share \(D\) as a common out-neighbor.

12.2.4 Neighborhood Union in Directed Graphs

Similarly, we can compute the union of neighborhood sets to identify the total set of unique nodes connected to either \(u\) or \(v\) (or both):

In-Neighborhood Union (\(N^{in}(u) \cup N^{in}(v)\)): The total set of unique nodes that send a directed edge to either \(u\) or \(v\).

Out-Neighborhood Union (\(N^{out}(u) \cup N^{out}(v)\)): The total set of unique nodes that receive a directed edge from either \(u\) or \(v\).

Using our examples from Figure 12.1, the union of the in-neighborhoods of \(C\) and \(D\) is: \[ N^{in}(C) \cup N^{in}(D) = \{B, E, G\} \]

And the union of the out-neighborhoods of \(E\) and \(G\) is: \[ N^{out}(E) \cup N^{out}(G) = \{C, D, F\} \]

12.3 Node Degree in Directed Graphs

Because in a directed graph each node has two distinct sets of neighbors, we can compute two versions of degree for the same node, corresponding directly to the cardinalities of their neighborhood sets.

12.3.1 Indegree

For any node \(i\), we can count the number of directed edges that have node \(i\) as their destination node. Since each incoming arrow comes from an in-neighbor of node \(i\), the indegree (denoted \(k^{in}_i\)) is mathematically defined as the cardinality of the in-neighborhood set of that node:

\[ k^{in}_i = |N^{in}(i)| \tag{12.1}\]

12.3.2 Outdegree

Additionally, for any node \(i\), we can count the number of directed edges that have node \(i\) as their source node. Since each outgoing arrow goes to an out-neighbor of node \(i\), the outdegree (denoted \(k^{out}_i\)) is mathematically defined as the cardinality of the out-neighborhood set of that node:

\[ k^{out}_i = |N^{out}(i)| \tag{12.2}\]

12.3.3 Concrete Examples

Let’s see how this works in practice by calculating the indegree and outdegree as neighborhood cardinalities for nodes \(B\) and \(D\) in Figure 12.1.

12.3.3.1 Node B

  • Neighborhood Sets:
    • In-neighborhood set: \(N^{in}(B) = \{A, D\}\)
    • Out-neighborhood set: \(N^{out}(B) = \{A, C, D\}\)
  • Degree Calculation:
    • Indegree: \(k^{in}_B = |N^{in}(B)| = |\{A, D\}| = 2\). This tells us that node \(B\) has two incoming connections.
    • Outdegree: \(k^{out}_B = |N^{out}(B)| = |\{A, C, D\}| = 3\). This tells us that node \(B\) has three outgoing connections.

12.3.3.2 Node D

  • Neighborhood Sets:
    • In-neighborhood set: \(N^{in}(D) = \{B, E, G\}\)
    • Out-neighborhood set: \(N^{out}(D) = \{B\}\)
  • Degree Calculation:
    • Indegree: \(k^{in}_D = |N^{in}(D)| = |\{B, E, G\}| = 3\). This tells us that node \(D\) has three incoming connections.
    • Outdegree: \(k^{out}_D = |N^{out}(D)| = |\{B\}| = 1\). This tells us that node \(D\) has one outgoing connection.

Can you calculate the indegree and outdegree as neighborhood cardinalities for node \(C\) in Figure 12.1?

The graph-theoretic concepts of indegree and outdegree have clear sociological interpretations. In a social network, for instance, a node having a large outdegree (large out-neighborhood cardinality) indicates a sociable person (someone active in sending out connections), while having a large indegree (large in-neighborhood cardinality) can indicate a popular person or an actor of high prestige (someone whom many others want to connect with).

12.3.4 Types of Nodes in Directed Graphs

In a directed graph, we can categorize (non-isolate) nodes based on their sending and receiving behavior (Harary et al. 1965), and thus based on their indegree and outdegree:

  • Receivers: Nodes that receive ties but do not send them. For receiver nodes, indegree \(k^{in} > 0\) and outdegree \(k^{out} = 0\). For instance, in Figure 12.1, node C has an indegree of 2 and an outdegree of 0, making it a receiver node.
  • Carriers: Nodes that both receive and send ties. For carrier nodes, \(k^{in} > 0\) and \(k^{out} > 0\). For instance, in Figure 12.1, node A has an indegree of 1 and an outdegree of 2, while node B has an indegree of 2 and an outdegree of 3, making both nodes carriers.
  • Transmitters: Nodes that send ties but do not receive them. For transmitter nodes, \(k^{in} = 0\) and \(k^{out} > 0\). For instance, in Figure 12.1, node E has an indegree of 0 and an outdegree of 2, making it a transmitter node.

12.3.5 Directed Degree Sets

Computing the degrees of all nodes in a directed network yields two separate vectors (called directed degree sets), each of length \(n\): the indegree set (written \(\mathbf{k}^{in}\)) and the outdegree set (written \(\mathbf{k}^{out}\)).

For the directed graph in Figure 12.1, these sets list each node’s incoming and outgoing degrees:

\[ \mathbf{k}^{in} = (k^{in}_A, k^{in}_B, \dots, k^{in}_G) = (2, 2, 2, 3, 0, 2, 0) \]

\[ \mathbf{k}^{out} = (k^{out}_A, k^{out}_B, \dots, k^{out}_G) = (2, 3, 0, 1, 2, 1, 2) \]

12.3.6 Directed Degree Sequences

When we arrange the elements of a degree set in decreasing order, from largest to smallest, we obtain the degree sequence. In directed graphs, this gives us two distinct sequences:

The Indegree Sequence (\(\mathbf{d}^{in}\)): For Figure 12.1, ordering the indegree set yields: \[ \mathbf{d}^{in} = (3, 2, 2, 2, 2, 0, 0) \]

The Outdegree Sequence (\(\mathbf{d}^{out}\)): Ordering the outdegree set yields: \[ \mathbf{d}^{out} = (3, 2, 2, 2, 1, 1, 0) \]

12.3.7 Minimum and Maximum Degree in Directed Graphs

We can examine the upper and lower bounds of connectivity in a directed network by taking the maximum and minimum values of the directed degree sets. This yields four distinct metrics:

the Maximum Indegree (\(k^{in}_{max}\)): The highest number of incoming ties received by any node: \[ k^{in}_{max} = \max(\mathbf{k}^{in}) = 3 \quad (\text{Node } D) \]

The Minimum Indegree (\(k^{in}_{min}\)): The lowest number of incoming ties received by any node: \[ k^{in}_{min} = \min(\mathbf{k}^{in}) = 0 \quad (\text{Nodes } E \text{ and } G) \]

The Maximum Outdegree (\(k^{out}_{max}\)): The highest number of outgoing ties sent by any node: \[ k^{out}_{max} = \max(\mathbf{k}^{out}) = 3 \quad (\text{Node } B) \]

The Minimum Outdegree (\(k^{out}_{min}\)): The lowest number of outgoing ties sent by any node: \[ k^{out}_{min} = \min(\mathbf{k}^{out}) = 0 \quad (\text{Node } C) \]

12.3.8 Indegree and Outdegree Range

The arithmetic difference between the maximum and minimum degrees represents the heterogeneity range of connectivity in the digraph:

The Indegree Range (\(k^{in}_r\)): The gap between the most popular and least popular nodes: \[ k^{in}_r = k^{in}_{max} - k^{in}_{min} = 3 - 0 = 3 \]

The Outdegree Range (\(k^{out}_r\)): The gap between the most active sender and the least active sender: \[ k^{out}_r = k^{out}_{max} - k^{out}_{min} = 3 - 0 = 3 \]

12.4 Directed Graph Metrics

Several basic graph-level metrics differ conceptually or mathematically when applied to directed graphs.

12.4.1 Directed Graph Maximum Size

As we saw in Chapter 7, the graph size is the number of edges (or arcs) \(m\) in the graph. The maximum size represents the maximum possible number of edges that can exist in a graph with \(n\) nodes.

In an undirected graph, loops are not allowed, meaning the maximum possible number of edges is \(\frac{n(n - 1)}{2}\). However, in a directed graph, edges have directionality, which means there can be two directed edges (arcs) between any pair of nodes—one in each direction (e.g., \(u \rightarrow v\) and \(v \rightarrow u\)).

Therefore, the maximum possible number of directed edges in a directed graph of order \(n\) is exactly twice that of an undirected graph:

\[ m_{max} = n(n - 1) \tag{12.3}\]

For our directed graph in Figure 12.1 of order \(n = 7\):

\[ m_{max} = 7(7 - 1) = 7(6) = 42 \]

This tells us that in a network of 7 nodes, there are 42 possible directed pathways.

12.4.2 Directed Graph Density

The density \(d(G)^d\) of a directed graph measures how many directed ties exist compared to how many directed ties are possible. It is computed as the ratio of the observed number of directed edges \(m\) to the maximum possible number of directed edges:

\[ d(G)^d = \frac{m}{n(n-1)} \tag{12.4}\]

If we apply this to the directed graph in Figure 12.1, where we observe \(m = 11\) directed edges among \(n = 7\) nodes:

\[ d(G)^d = \frac{11}{7(6)} = \frac{11}{42} \approx 0.262 \quad (26.2\%) \]

This indicates that approximately 26.2% of all possible directed edges in the network are actually observed. Another way to interpret density is as the probability that, if we were to select two random nodes \(u\) and \(v\) from the network, the directed dyad from \(u\) to \(v\) would be connected by an arrow.

12.4.3 Average Indegree and Outdegree

We can compute the average (mean) connectivity across nodes in a directed graph. Because each node has two distinct degrees, we can calculate both the average indegree (\(\bar{k}^{in}\)) and the average outdegree (\(\bar{k}^{out}\)):

The Average Indegree (\(\bar{k}^{in}\)): The sum of all indegrees divided by the number of nodes: \[ \bar{k}^{in} = \frac{\sum_i k^{in}_i}{n} \] * Average Outdegree (\(\bar{k}^{out}\)): The sum of all outdegrees divided by the number of nodes: \[ \bar{k}^{out} = \frac{\sum_i k^{out}_i}{n} \]

An important result in graph theory is that the average indegree and the average outdegree are always mathematically identical:

\[ \bar{k}^{in} = \bar{k}^{out} = \bar{k} = \frac{m}{n} \tag{12.5}\]

This identity exists because every directed edge (arc) must start at exactly one node (contributing to that node’s outdegree) and end at exactly one node (contributing to that node’s indegree). Consequently, the sum of all indegrees and the sum of all outdegrees are both exactly equal to the total number of edges \(m\) (\(\sum_i k^{in}_i = \sum_i k^{out}_i = m\)).

For our directed graph in Figure 12.1 (\(m = 11\), \(n = 7\)):

\[ \bar{k} = \frac{m}{n} = \frac{11}{7} \approx 1.57 \]

12.5 Degree Variance in Directed Graphs

Once we have calculated the average degree, we can measure the heterogeneity (or inequality) in connectivity across nodes by computing the degree variance. In directed graphs, because each node has two distinct degrees, we must compute two separate variances: indegree variance and outdegree variance.

Just like in the undirected case, the degree variance represents the average squared deviation of each node’s degree from the graph’s average degree.

12.5.1 Indegree Variance (\(\mathcal{v}^{in}(G)\))

The indegree variance measures the inequality in incoming connections (popularity/prestige) across nodes in the network:

\[ \mathcal{v}^{in}(G) = \frac{\sum_i (k^{in}_i - \bar{k})^2}{n} \tag{12.6}\]

12.5.2 Outdegree Variance (\(\mathcal{v}^{out}(G)\))

The outdegree variance measures the inequality in outgoing connections (sociability) across nodes:

\[ \mathcal{v}^{out}(G) = \frac{\sum_i (k^{out}_i - \bar{k})^2}{n} \tag{12.7}\]

Note that because \(\bar{k}^{in} = \bar{k}^{out} = \bar{k} = m/n\), both formulas use the same average degree, but the individual node values \(k^{in}_i\) and \(k^{out}_i\) can differ, yielding distinct variances.

Let’s compute both variances for the directed graph in Figure 12.1 (where \(n = 7\), \(m = 11\), and \(\bar{k} = 11/7 \approx 1.57\)).

Table 12.1 lists each node’s indegree, outdegree, and squared deviations from the average degree.

Using the sums of the squared deviations from Table 12.1, we calculate the variances:

Indegree Variance: \[ \mathcal{v}^{in}(G) = \frac{7.71}{7} \approx 1.10 \]

Outdegree Variance:

\[ \mathcal{v}^{out}(G) = \frac{5.71}{7} \approx 0.82 \]

In this network, the indegree variance (\(1.10\)) is higher than the outdegree variance (\(0.82\)). Sociologically, this indicates that there is more inequality in the popularity/prestige of nodes (receiving ties) than in their sociability (sending ties). In other words, incoming connections are more heavily concentrated on a few “popular” nodes (like node \(D\)) while others are left as complete non-receivers (like \(E\) and \(G\)).

12.6 Special Classes of Directed Graphs

By imposing structural restrictions on reciprocity, degree, or edge directionality, we can define special classes of directed graphs.

12.6.1 Symmetric Directed Graphs

If, in a directed graph, every pair of connected nodes is linked by a bi-directional, reciprocal relationship, the graph is a symmetric directed graph.

Figure 12.2 shows a symmetric directed graph with eight nodes and sixteen bi-directional edges (thirty-two directed arcs). For every edge from \(u\) to \(v\), there exists a corresponding edge from \(v\) to \(u\).

12.6.2 Functional Graphs

A functional graph is a special kind of digraph built by imposing the restriction that each node can only have a single out-neighbor (i.e., the outdegree of every node is exactly equal to one, \(k_{out} = 1\)). Functional graphs have important applications in the anthropological analysis of kinship exchange systems in traditional societies (Hage and Harary 1996).

Figure 12.3 shows a functional graph with eight nodes. If a graph \(G\) is a functional graph, then the number of nodes \(V\) is always equal to the number of directed edges \(E\) (\(V = E = 8\)). This is mathematically constrained because each of the \(V\) nodes sends out exactly one edge.

12.6.3 Oriented Graphs

An oriented graph is a directed graph containing no symmetric (reciprocal) dyads. If there is a directed link from \(u\) to \(v\), there cannot be a link from \(v\) to \(u\). It is the structural opposite of a symmetric directed graph.

In the oriented graph shown in Figure 12.4, every connected pair is linked only by a one-way directed tie; reciprocal dyads are forbidden by the nature of the relationship (e.g., strict hierarchy or non-reversible flows).

12.6.4 Anti-Symmetric Ties and Directed Tree Graphs

As we saw in Chapter 5, a relation is anti-symmetric if reciprocity is strictly forbidden. If A is anti-symmetrically connected to B, then B cannot send the same type of tie back to A. When these relations are concatenated across multiple nodes, they can form a directed tree graph (for a more general consideration of tree graphs see Chapter 17).

Consider the relationship “being the father of.” You have a father, your father has a father, and so on. This creates a generational lineage represented as a tree.

In Figure 17.1, node \(A\) is the earliest common ancestor, and all other nodes are anti-symmetrically related to it. Similarly, formal organizational structures where subordinates “take orders from” a single supervisor generate tree graphs. A notable property of tree graphs is that every node (except the root) has exactly one in-neighbor (one supervisor or one father), but can have multiple out-neighbors (children or subordinates).
