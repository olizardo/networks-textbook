1 Groups and Cohesion

When we are studying a social system a common question that comes up is whether the social structure is cohesive or fragmented. That is, we ask whether the system is composed of a lot of overlapping subgroups which are themselves densely connected, or whether it is held together by just a few links or people.

This would be difference between the networks represented by the two graphs shown in Figure 1.1A and 1.1B. The graphs are of the same order (they have identical node sets) but they are of different size. Figure 1.1A shows a highly cohesive social system, with many interlinked connections across actors creating a densely knit structure. The graph in Figure 1.1B is much less well-connected and seems like it could split apart very easily.

Figure 1.1: A series of undirected graphs.

So how can we think of cohesiveness in network terms? As you may have already gathered, the great thing about graph theory is that it allows us to move beyond vague terminology like “split apart,” “fragmented” and “densely knit.” Instead, we can precisely specify what we mean when a graph is cohesive versus when it is fragmented.

1.1 Cohesiveness and Adhesiveness

There are two ways social networks analysts have specified the concept of cohesion, so we will need two separate terms. Both use the same idea: Namely, a system is stronger and better knit together if it is resistant to disruption when we remove actors from the system. Disruption, in its turn, is defined by graph connectivity. So this leads to the technical definition of cohesion. A network is cohesive if we we can remove many actors from it and the remaining graph remains connected. How many actors can be removed in this way has a special name we will get to in a bit.

But of course, a graph can also transition from being connected to disconnected when we remove edges from it. This is why we need a second concept, referred to as adhesion. A network is adhesive if we can remove many edges from it without disconnecting the graph that represents the network. So clearly, very dense networks like the ones shown in 1.1A are more adhesive than sparse networks like the ones shown in Figure 1.1B.

The property of cohesiveness can be exemplified by comparing the graphs shown in Figures 1.1B and 1.1D. The graph shown in Figure 1.1D is exactly the same as the one on shown in Figure Figure 1.1B, except that node A has been removed from the network.1 As you may recall from the graph theory lesson, this means that the first graph is an node-deleted subgraph of the second. As you can see, removing A from Figure 1.1B results a disconnected graph featuring nodes B, C, and D in their own component isolated from the rest (now the graph’s giant component).

Figures 1.1A and 1.1C shows the same comparison for the more densely knit network. The graph shown in Figure 1.1C is exactly the same as the one shown in Figure 1.1A, except that node A has been removed from the network. As you can see, removing node A from the original graph makes little difference regarding connectivity, the graph shown in Figure 1.1C is still heavily connected, demonstrating that the graph shown in Figure 1.1A has higher levels of cohesiveness than the left-hand graph shown in Figure 1.1B.

Similarly, the property of adhesiveness can be exemplified by comparing Figures 1.1B and 1.1F. The graph shown in 1.1F is exactly the same as the one shown in 1.1B, except that edges AC and AD have been removed from the network.2 As you may recall from the graph theory lesson, this means that the first graph is an edge-deleted subgraph of the second. Like before, removing edges AC and AD from Figure 1.1B results in a disconnected graph featuring nodes B, C, and D in their own component isolated from the rest (now the graph’s giant component).

Figures 1.1A and 1.1E shows the same comparison for the more densely knit network. The graph shown in Figure 1.1C is exactly the same as the one shown in Figure 1.1A, except that edges AC and AD have been removed from the network. As you can see, removing these edges from the original graph makes little difference regarding connectivity, the graph shown in Figure 1.1E is still heavily connected, demonstrating that the graph shown in Figure 1.1A has higher levels of adhesiveness than the left-hand graph shown in Figure 1.1B.

1.2 Pairwise Node and Edge Connectivity and Cutsets

To quantify cohesion in a social system it is useful to define notions of the strength of indirect connectivity between pairs nodes in a graph. Just like at the graph level, we want to say that a pair of nodes in a graph has a more robust indirect connections, if the removal of other nodes or edges from the graph does not disconnect them.

This leads to two definitions of the strength of indirect pairwise connectivity of nodes.

In a graph, the node connectivity, written \(NC_{uv}\), of two nodes in a graph is equal to the minimum number of nodes that would have to be removed for them to become disconnected. Similarly, the edge connectivity, written \(EC_{uv}\), of two nodes in a graph is equal to the minimum number of edges that would have to be removed for them to become disconnected.

For instance, in the graph shown in Figure 1.2, the node connectivity of nodes A and B is three (\(NC_{AB} = 3\)) because it would take removing a minimum of three nodes (C, D, and E) to disconnect them. Thus, we say that the set of nodes \(\{C, D, E\}\) is the pairwise node cutset of nodes A and B. In the same way, the node connectivity between nodes C and D is two \(NC_{CD} = 2\) because it would take removing a minimum of two nodes (A and B) to disconnect them. Thus, we say that the set of nodes \(\{A, B\}\) is the pairwise node cutset of nodes C and D. Table 1.1 show the pairwise node connectivities for all the non-adjacent nodes in Figure 1.2.

Similarly, in the graph shown in Figure 1.2, the edge connectivity of nodes A and B is three (\(EC_{AB} = 3\)) because it would take removing a minimum of three edges (AC, AD, and AE or BC, BD, and BE) to disconnect them. Thus, we say that either the edge sets \(\{AC, AD, AE\}\) or \(\{BC, BD, BE\}\) are the pairwise edge cutsets of nodes A and B. This means that neither edge or node cutsets have to be unique. In the same way, the edge connectivity between nodes C and D is two (\(EC_{CD} = 2\)) because it would take removing a minimum of two edges (e.g., DA or DB) to disconnect them. Accordingly, the edge set \(\{DA, DB\}\) is the pairwise edge cutset of nodes C and D in Figure 1.2.
