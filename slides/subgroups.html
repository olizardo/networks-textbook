Menger’s theorem

  • Menger’s theorem states that if a graph has \(k\)-connectivity \(= n\):
    • There are at least \(n\) paths that don’t share nodes connecting every non-adjacent pair of nodes
    • The \(k\)-connector nodes stand on each of these paths
  • This graph has \(k\)-connectivity = 3 (removing the three red nodes disconnects the graph)

Menger’s theorem: counting the paths

  • The two non-adjacent green nodes are indirectly connected in three separate (node-independent) ways!
    • Path 1: \(A \to B \to E\)
    • Path 2: \(A \to C \to E\)
    • Path 3: \(A \to D \to E\)
  • This is an important result in graph theory!

Menger’s theorem: independent paths

  • In a graph, paths that don’t share nodes are called node-independent paths
  • And paths that don’t share edges are called edge-independent paths
  • Another way of stating Menger’s theorem:
    • If a graph has \(k\)-connectivity \(= n\), there are at least \(n\) node-independent paths connecting each pair of non-adjacent nodes in the graph!

Pairwise node connectivity

  • For any pair of non-adjacent nodes, \(u\) and \(v\):
  • The pairwise node cutset \(\kappa_{uv}\) is the number of nodes that would have to be removed for them to be disconnected
  • If \(\kappa_{uv} = n\), that means there are at least \(n\) node-independent paths linking \(u\) and \(v\)
  • Two paths are node-independent wherever the inner nodes in each path are different

Part 6: Cohesion

Graph connectivity as social cohesion

  • \(k\)-connectivity (graph theory) can represent the concept of social cohesion (network theory):
    • The larger the (edge, node) cutset, the more cohesive (integrated) groups are with one another
    • The smaller the (edge, node) cutset, the less cohesive and more potentially fragmented the group structure is

Graph connectivity as social cohesion

  • The more \(k\)-connectivity, the more cohesive (integrated) the group
    • More people would have to be removed to disrupt the group
  • Any graph can be split into subgraphs with any given level of \(k\)-connectivity

Part 7: Cohesive Blocking

Cohesive blocking

  • The idea of cutsets leads to the Cohesive Blocking approach for the identification of nested cohesive subgroups (Moody and White 2003):
    1. Identify the \(k\)-connectivity of the input graph
    2. Remove the \(k\)-cutset (vertices)
    3. Do the same on the resulting subgraphs until no more subdivisions can be obtained

Cohesive blocking: recursion (cont.)

Part 8: Lambda Sets

Using edge connectivity to find cohesive subsets

  • We can use pairwise edge connectivity \(\lambda(u, v)\) to recursively find Lambda Sets (Borgatti, Everett, & Shirey, 1990).
  • The core property of lambda sets:
    • The pairwise edge connectivity between nodes inside a lambda set is always strictly larger than the edge connectivity between any node inside the set and any node outside the set.
    • This mathematically guarantees that group members have stronger indirect ties with each other than with any outsider!
  • Let’s walk through the hierarchical partition algorithm on a 16-node graph.

Lambda sets: step-by-step splitting

  • Step 1: start with graph \(G\). Its edge connectivity is \(\lambda(G) = 3\); removing the minimum edge cutset \(\{AF, AL, CP\}\) splits the graph.

Lambda sets: step-by-step splitting

  • Step 2: remove \(\{AF, AL, CP\}\). This splits the graph into a clique component \(\{A, B, C, D\}\) (\(\lambda = 3\)) and a giant component (\(\lambda = 2\)).

Lambda sets: step-by-step splitting (cont.)

  • Step 3: remove \(\{HJ, HM\}\). This disconnects the giant component, yielding a new component and a clique of size 4.

Lambda sets: step-by-step splitting (cont.)

  • Step 4: remove \(\{JN, IN\}\). Disconnecting the final component reveals four cohesive subgroups of size 4 — three are cliques, and \(\{I, J, K, L\}\) is missing only the \(IL\) tie (but its members remain far more connected to each other than to outsiders).

Dendrogram of lambda sets

  • Because lambda sets are hierarchically nested, we can plot their nested relationship using a dendrogram.
  • Properties of lambda sets:
    • At any given partition height, each node belongs to exactly one lambda set.
    • Smaller, tighter lambda sets are cleanly nested within larger, looser ones.
    • Excellent for showing multi-level nested structures (e.g., departments nested in divisions, nested in the firm).

Part 9: K-Core Decomposition & Core-Periphery Structures

Core-periphery structures

  • Sometimes networks are organized so that there is a cohesive subgroup hidden inside a set of less well-connected nodes
  • The cohesive subgroup is called the core
  • The other nodes are called the periphery
  • These are called core-periphery structures

K-core decomposition: the onion method

  • The method of \(k\)-core decomposition helps us find well-connected cores in networks:
    1. Begin with the less well-connected nodes (e.g., degree = 1)
    2. Remove those
    3. Continue removing nodes based on degree to reveal deeper “shells” (like an onion)
    4. Find the hidden core!

K-core decomposition: k = 0

  • Start with the full 21-node network

K-core decomposition: k = 1

  • Remove the least well-connected nodes first: the six pendant nodes (\(P\) to \(U\))

K-core decomposition: k = 2

  • Continue peeling: the six cycle nodes (\(J\) to \(O\)) now have the lowest degree

K-core decomposition: k = 3

  • The next shell (\(B\), \(D\), \(F\), \(G\), \(H\), \(I\)) comes off

K-core decomposition: the core

  • Nodes \(A\), \(C\), and \(E\) are the core of this network
  • Everything else was periphery, peeled away shell by shell

Mathematical core-periphery models

  • To formally test for core-periphery structures, we fit ideal blockmodels to our observed adjacency matrix:
  • Ideal core-periphery adjacency matrix:
    • The Core block is a 1-block (density \(\approx\) 1.0).
    • The Core-to-Periphery blocks are 1-blocks (density \(\approx\) 1.0, periphery is tied to the core).
    • The Periphery-to-Periphery block is a 0-block (density \(\approx\) 0.0, peripheral nodes do not connect).
  • \[ \mathbf{Adj} = \begin{pmatrix} \mathbf{Core} & \mathbf{Core/Periph} \\ \mathbf{Periph/Core} & \mathbf{Periphery} \end{pmatrix} = \begin{pmatrix} \mathbf{1} & \mathbf{1} \\ \mathbf{1} & \mathbf{0} \end{pmatrix} \]
  • This mathematical structure allows us to predict network outcomes and analyze systemic robustness.

Part 10: Summary of Key Terms

Summary of key terms (I)

  • Subgraph: A subset (\(G'\)) of the node and the edge set of a graph (\(G\))
  • Connected subgraph: All nodes in the subgraph can reach other nodes in the subgraph via some path within the subset of edges
  • Maximal subgraph: A subgraph is maximal with respect to property \(p\) (e.g., completeness, connectivity) when no more nodes or edges can be added to the subgraph without losing that property
    • Maximally connected subgraph, maximally complete subgraph, etc.
  • Clique: Maximally complete subgraph
  • Clique size: Number of nodes in a clique
  • \(n\)-Clique: A subgraph in which every node can reach every other node inside the subgraph via a path of at most \(n\) steps

Summary of key terms (II)

  • Connected graph: All nodes in the graph can reach every other node via a path regardless of length (\(l < \infty\))
  • Disconnected graph: Some nodes in the graph cannot reach other nodes via any path (e.g., for at least one pair of nodes \(l_{uv} = \infty\))
  • Components: Maximally connected subgraphs inside a disconnected graph
  • Giant component: The maximally connected subgraph in a disconnected graph with the largest number of nodes
  • \(k\)-Connected component: A component that remains connected after the removal of any \(k-1\) nodes (its node connectivity is \(k\))

Summary of key terms (III)

  • Bridges: An edge that if it were removed would disconnect the graph
  • Edge cutset: Minimum number of edges whose removal would disconnect the graph
  • Node cutset: Minimum number of nodes whose removal would disconnect the graph
  • uv-cutset: Number of nodes whose removal would disconnect a pair of nodes (\(uv\))
  • Menger’s theorem: If a graph has \(k\)-connectivity \(= n\), every pair of non-adjacent nodes is connected by at least \(n\) node-independent paths
  • Cohesive blocking: A way to find densely connected subgroups in a graph by removing nodes in the node cutset (Moody & White 2003)
