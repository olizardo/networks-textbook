Advanced Network Matrices

Beyond the Adjacency Matrix

Part 1: The Reachability Matrix Step-by-Step

What is Reachability?

  • In a directed graph, the adjacency matrix only records paths of length 1 (direct arrows).
  • Reachability expands our view to indirect paths of any length:
    • Node \(j\) is reachable from node \(i\) if there exists a directed path starting at \(i\) and terminating at \(j\).
    • Example: If we have \(A \rightarrow C \rightarrow E \rightarrow D\), then \(A\) can reach \(D\) via a path of length 3, even if no direct arrow \(A \rightarrow D\) exists.
  • Representing these reachability relations systematically yields the Reachability Matrix (\(\mathbf{D^r}\)):
    • Binary matrix where \(D^r_{ij} = 1\) if \(i\) can reach \(j\) via a path of any length, else \(0\).

Step 1: Filling Row A (Actor A’s Reachability)

Let’s trace which nodes can be reached by starting a directed walk at node A.

  • Can A reach B?
    • No (\(d^r_{AB} = 0\)). No directed path goes against \(B \rightarrow E\).
  • Can A reach C?
    • Yes (\(d^r_{AC} = 1\)). Direct link \(A \rightarrow C\).
  • Can A reach D?
    • Yes (\(d^r_{AD} = 1\)). Direct link \(A \rightarrow D\).
  • Can A reach E?
    • Yes (\(d^r_{AE} = 1\)). Path \(A \rightarrow C \rightarrow E\) exists.
  • Row A: (--, 0, 1, 1, 1)

Step 2: Filling Row B (Actor B’s Reachability)

Let’s trace which nodes can be reached by starting a directed walk at node B.

  • Can B reach A or C?
    • No (\(d^r_{BA} = 0\), \(d^r_{BC} = 0\)). No paths go left from E.
  • Can B reach D?
    • Yes (\(d^r_{BD} = 1\)). Path \(B \rightarrow E \rightarrow D\) of length 2.
  • Can B reach E?
    • Yes (\(d^r_{BE} = 1\)). Direct link \(B \rightarrow E\).
  • Row B: (0, --, 0, 1, 1)

Step 3: Completed Reachability Matrix

Repeating this row-by-row analysis yields the completed reachability matrix.

  • Receiver Node (D): Row D is all \(0\)s (D can’t reach anyone).
  • Transmitter Node (B): Column B is all \(0\)s (B can’t be reached by anyone).

Part 2: Directed Graphs: Flavors of Connectivity

Directed Graph Connectivity

  • In undirected graphs, connectivity is simple: either there is a path between every pair (connected) or there is not (disconnected).
  • In directed graphs, edge directionality creates three distinct major levels of connectivity:
    1. Strongly Connected: Every node can reach every other node.
    2. Unilaterally Connected: For every pair \(\{u, v\}\), at least one node can reach the other (\(u \rightarrow v\) OR \(v \rightarrow u\)).
    3. Weakly Connected: Nodes are connected only if we ignore the directions of the arrows (connected via semipaths).
  • Let’s see how these levels map directly to zeros and ones in the reachability matrix.

Case 1: Strongly Connected Graphs

Every pair of nodes is mutually reachable.

Part 3: Graph Connectedness & Geodesic Distances

Measuring Graph Connectedness (\(C\))

  • Graph Connectedness (\(C\)) measures the overall capacity of a network to facilitate connections.
  • It is defined as the density of the reachability matrix (excluding diagonal cells):
    • \[C = \frac{\sum_{i \neq j} D^r_{ij}}{N(N-1)}\]
  • For our weakly connected 8-node graph:
    • Sum of all cells containing a \(1\) is 48.
    • Total possible off-diagonal cells: \(8(7) = 56\).
    • \[C = \frac{48}{56} \approx 0.86\]

Reachability Density

Value Meaning
\(C = 1.0\) Strongly connected network (perfect reachability, all-ones matrix).
\(C < 1.0\) Unilaterally or weakly connected network (contains zeros).
\(C = 0.0\) Completely disconnected network (all zeros).

Part 4: The Geodesic Distance Matrix Step-by-Step

What is Geodesic Distance?

  • While reachability tells us if node \(i\) can reach node \(j\), the Geodesic Distance Matrix (\(\mathbf{D^g}\)) tells us how far apart they are.
  • Geodesic Distance:
    • The length of the shortest path (in number of edges) connecting two vertices.
  • Matrix Rules:
    • Adjacent nodes get a geodesic distance of 1.0.
    • Nodes are at distance 0.0 from themselves: \(D^g_{ii} = 0\) for all diagonal cells.
    • If no directed or indirect path connects them, their geodesic distance is Infinity (\(\infty\)) or Inf.

Step 1: Distance Matrix (Undirected) - Adjacencies

We start with our undirected reference graph. Nodes with direct connections get a geodesic distance of 1.0.

Part 5: Node Eccentricity and Graph Diameter

Node Eccentricity and Graph Diameter

  • We can extract key distance-based centralities directly from our completed Geodesic Distance Matrix:
  • Node Eccentricity (\(e(v)\)):
    • The maximum geodesic distance between node \(v\) and any other node in the graph:
    • \[e(v) = \max_{j \neq v} D^g_{vj}\]
    • Measures the “worst-case” distance for information to reach or leave node \(v\). Nodes with low eccentricity are highly central.
  • Graph Diameter (\(d\)):
    • The maximum eccentricity among all nodes in the graph (the longest shortest path):
    • \[d = \max_v e(v) = \max_{i, j} D^g_{ij}\]

Visualizing Node Eccentricity

Eccentricity is calculated as the maximum value in each row of the Geodesic Distance Matrix (excluding diagonal 0s).

Part 6: The Common-Neighbors (Neighborhood Overlap) Matrix

What is Neighborhood Overlap?

  • Recall that the neighborhood \(\mathcal{N}(i)\) is the set of vertices adjacent to node \(i\).
  • Neighborhood Overlap:
    • The number of common neighbors shared by two nodes, relative to their total number of distinct neighbors.
  • Jaccard Similarity Coefficient (\(J_{ij}\)):
    • Formally, the overlap between node \(i\) and node \(j\) is:
    • \[J_{ij} = \frac{|\mathcal{N}(i) \cap \mathcal{N}(j)|}{|\mathcal{N}(i) \cup \mathcal{N}(j)|} = \frac{\text{Common Neighbors}}{\text{Total Unique Neighbors}}\]
  • Placing these pairwise overlap scores into a matrix yields the Neighborhood Overlap Matrix (\(\mathbf{O}\)).

Visualizing Neighborhood Overlap

Overlap measures the proportion of shared neighbors (Green node) relative to unique neighbors.

Neighborhood Overlap Matrix (\(\mathbf{O}\))

A B C D E
A – 0.00 0.25 0.50 0.40
B 0.00 – 0.33 0.33 0.33
C 0.25 0.33 – 0.50 0.50
D 0.50 0.33 0.50 – 0.50

  • Cell \(O_{AC} = 0.25\) represents the overlap between A (red) and C (red).
  • Their sole common neighbor is node D (green).

Step-by-Step Calculation: Node \(A\) and \(C\)

Let’s compute the neighborhood overlap \(O_{AC}\) for nodes \(A\) and \(C\) using our highlighted graph:

  • \(A\)’s Neighborhood: \(\mathcal{N}(A) = \{C, D\}\) (degree \(k_A = 2\))
  • \(C\)’s Neighborhood: \(\mathcal{N}(C) = \{A, D, E\}\) (degree \(k_C = 3\))
  • Intersection (Common Neighbors):
    • \(\mathcal{N}(A) \cap \mathcal{N}(C) = \{D\}\) (Cardinality = 1)
    • Node \(D\) is connected to both \(A\) and \(C\) (shown in green).
  • Union (Total Unique Neighbors):
    • \(\mathcal{N}(A) \cup \mathcal{N}(C) = \{A, C, D, E\}\) (Cardinality = 4)
  • Jaccard Overlap:
    • \[O_{AC} = \frac{|\{D\}|}{|\{A, C, D, E\}|} = \frac{1}{4} = 0.25\]

Summary of Advanced Matrices

  • Reachability Matrix (\(\mathbf{D^r}\)):
    • Records whether node \(i\) can reach \(j\) via any path. Enables calculation of Graph Connectedness (\(C\)) as matrix density.
  • Geodesic Distance Matrix (\(\mathbf{D^g}\)):
    • Records shortest path lengths. Provides the basis for measuring Node Eccentricity (row max) and Graph Diameter (global max).
    • Unreachable pairs are recorded as Infinity (\(\infty\)) or Inf.
  • Neighborhood Overlap Matrix (\(\mathbf{O}\)):
    • Records the Jaccard overlap coefficient (\(\frac{\text{intersection}}{\text{union}}\)) of neighbors, capturing structural similarity.
