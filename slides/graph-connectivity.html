Graph Theory: Paths & Connectivity

The Basics of Social Network Analysis

Part 1: Indirect Connections & Paths

Adjacency vs. Indirect Connections

  • Adjacency captures direct connections between nodes:
    • If \(A\) is adjacent to \(B\), they share an edge.
  • But many network processes operate indirectly:
    • We must look beyond immediate contacts to the “friends of our friends.”
  • In graph theory, indirect connections are formalized using three core concepts:
    • Path, Connectivity, and Reachability.

Why Indirect Connections Matter

  • Indirect pathways are the engine of diffusion and flow in a network.
  • They act as channels for:
    • Information & Gossip: Diffusing through chains of acquaintances (“six degrees of separation”).
    • Disease & Contagion: Spreading via intermediate, infected contacts.
    • Influence & Support: Reaching distant nodes through brokers.
  • Two strangers meeting at an airport who discover a common contact are connected by a path of length two.

What is a Path?

  • A path between \(u\) and \(v\) is an alternating sequence of nodes and edges that:
    • Begins with an origin node (\(u\)).
    • Ends with a destination node (\(v\)).
    • Does not repeat any nodes (which implies edges are not repeated either!).
  • Every path is actually a subgraph of the original graph, connected in a single line.

Anatomy of a Path

  • Let’s look at our red path from \(B\) to \(D\):
    • Written as: \(B-D = \{BE, ED\}\)
  • Key Elements:
    • Origin Node: \(B\) (the start of the sequence)
    • Destination Node: \(D\) (the end of the sequence)
    • Inner Nodes: \(E\) (the nodes in between)
  • Together, the origin and destination are called the end nodes of the path.
  • The length of a path (\(l\)) is the number of edges: \(l = 2\).

Multiple Paths of Different Lengths

  • The same two nodes can be connected via multiple distinct paths.
  • Let’s trace the pathways from \(B\) to \(A\):
    • \(P_1 = \{BE, ED, DA\} \quad (l = 3)\)
    • \(P_2 = \{BE, EC, CA\} \quad (l = 3)\)
    • \(P_3 = \{BE, ED, DC, CA\} \quad (l = 4)\)
    • \(P_4 = \{BE, EC, CD, DA\} \quad (l = 4)\)
  • Each path represents a valid, non-repeating sequence of contacts.

Shortest Paths & Geodesics

  • Shortest Path (Geodesic):
    • The path of minimum length connecting two nodes.
  • Geodesic Distance:
    • The length of the shortest path between two nodes (the “degrees of separation”).
  • For Nodes \(B\) and \(A\):
    • The geodesic distance is \(l = 3\).
    • There are multiple shortest paths (a tie between \(P_1\) and \(P_2\)).

What is a Cycle?

  • A cycle is a path of length 3 or larger that starts and ends on the same node.
  • In other words, origin and destination are identical, but inner nodes are unique.
  • Examples:
    • \(Cycle_1 = \{ED, DC, CE\} \quad (l = 3)\)
      • This is a triangle (closed triad), the smallest possible cycle.

Graph Girth: Shortest Cycle

  • Cycles are characterized by their length (number of edges).
  • Graph Girth:
    • The length of the shortest cycle in a graph.
    • In our undirected house graph on the right, the girth is 3.
    • This is the triangle \(\{ED, DC, CE\}\), highlighted in red.

Graph Circumference: Longest Cycle

  • Graph Circumference:
    • The length of the longest cycle in a graph.
    • In our undirected house graph on the right, the circumference is 4.
    • This is the cycle \(\{ED, DA, AC, CE\}\), highlighted in red.
    • Notice that node \(D\) and node \(C\) are connected directly, but we bypass that direct edge to form the longest cycle.

Walks and Trails

  • Walk: Any sequence of alternating nodes and edges from \(u\) to \(v\).
    • No restrictions: Nodes and edges can be repeated as much as you want!
    • e.g., \(\{AD, DC, CE, ED, DC, EC, EB\}\) is a walk.
  • Trail: A walk that does not repeat any edges.
    • Repeated nodes are allowed, but every edge in the sequence must be unique.
    • e.g., \(\{CA, AD, DC, CE, ED\}\) is a trail (nodes \(C\) and \(D\) are visited twice, but all edges are unique).

Walks: A Visual Example

  • Walk: \(B \rightarrow E \rightarrow C \rightarrow E \rightarrow D\) (length 4)
  • Characteristics:
    • Traverses the highlighted edges in red.
    • Repeats node E (visited twice).
    • Repeats edge E-C (traversed back and forth).
    • No restrictions on repetition!

Trails: A Visual Example

  • Trail: \(A \rightarrow C \rightarrow D \rightarrow E \rightarrow C \rightarrow B\) (length 5)
  • Characteristics:
    • Traverses the highlighted edges in red.
    • Repeats node C (visited twice).
    • No edges are repeated: All five edges (\(AC, CD, DE, EC, EB\)) are completely unique!

The Sequence Hierarchy

  • Path: A walk that does not repeat any nodes (which means edges cannot be repeated either).
  • The Nested Hierarchy:
    • Every path is a trail.
    • Every trail is a walk.
    • All paths are trails, and all trails are walks, but the reverse is not true!
  • Paths are the most restrictive, while walks are the least restricted.

Part 2: Directed Paths & Reachability

Paths in Directed Graphs (Digraphs)

  • In directed graphs, paths must strictly respect the direction of the arrows!
  • Let’s trace directed paths from \(A\) to \(B\) in our digraph:
    • \(P_1 = \{AC, CE, EB\} \quad (l = 3)\)
    • \(P_2 = \{AD, DE, EB\} \quad (l = 3)\)
    • \(P_3 = \{AC, CD, DE, EB\} \quad (l = 4)\)
  • But can we find any directed path from \(B\) to \(A\)?
    • No! All arrows lead away from \(A\) and toward \(B\).

Asymmetric Reachability

  • In directed networks, reachability is asymmetric:
    • \(A\) can reach \(B\) via path \(\{AD, DE, EB\}\) (\(l_{AB} = 3\)).
    • \(B\) cannot reach \(A\) (\(l_{BA} = \infty\)).
  • This asymmetric structure is a primary driver of inequality and unilateral flows in social networks (e.g. hierarchical power).

Mutual Reachability

  • Mutual Reachability:
    • Two nodes \(u\) and \(v\) are mutually reachable if there exists a directed path from \(u \rightarrow v\) AND from \(v \rightarrow u\).
  • The two paths do not have to be the same length!
  • Example: Nodes \(B\) and \(C\) are mutually reachable:
    • \(B\) reaches \(C\) via \(\{BE, ED, DC\} \quad (l = 3)\)
    • \(C\) reaches \(B\) via shortest path \(\{CE, EB\} \quad (l = 2)\)

Directed Cycles

  • A directed cycle is a cycle where all arrows flow in a single, continuous direction.
  • Example: Cycle starting and ending at \(C\)
    • \(\{CE, ED, DC\} \quad (l = 3)\)
  • Directed Acyclic Graphs (DAGs):
    • Directed graphs that contain no directed cycles.
    • e.g. strict organizational command structures.

Ignoring the Arrows: Semipaths

  • What if we want to trace connections in a directed graph but ignore the arrows?
  • This is called a semipath (or semicycle if it is a closed loop).
  • A semipath treats directed arcs as undirected edges.
  • Example: Semipath connecting \(B\) and \(A\)
    • \(\{BE, EC, CA\}\) (visualized in red on the right).

Part 3: Graph Connectivity & Components

Connected vs. Disconnected Graphs

  • Connected Graph:
    • An undirected graph where there exists a finite path between every pair of nodes (left).
  • Disconnected Graph:
    • An undirected graph where at least one pair of nodes is not connected by any path (right).
    • There is a “gap” splitting the graph into separate components.

Components and the Giant Component

  • Component:
    • A connected subgraph within a larger disconnected graph.
    • If a graph has more than one component, it is disconnected.
  • Giant Component:
    • The largest connected component in a disconnected graph.
    • In our 9-node graph (right), the component of order 6 \(\{A, B, C, D, E, F\}\) is the giant component.

Part 4: Node and Edge Connectivity (Bridges & Cutsets)

Edge Cutsets

  • Edge Cutset: Any set of edges whose removal disconnects the graph into two or more components.
  • Example: The set of edges {A-C, B-C} (highlighted in red) is an edge cutset of size 2.
    • Removing both edges isolates node C (and \(\{D, E\}\)) from \(\{A, B\}\).
  • Edge Connectivity (\(\lambda(G)\)): The size of the minimum edge cutset.

Bridges

  • Bridge: A single edge whose removal disconnects the graph (a cutset of size 1).
  • Example: The edge C-D (highlighted in red) is a bridge.
    • Removing C-D splits the network into two separate components: \(\{A, B, C\}\) and \(\{D, E\}\).
  • Bridges represent the most critical, yet vulnerable transmission links in a network.

The Sociological Power of Bridges

  • Mark Granovetter’s seminal paper “The Strength of Weak Ties” (1973):
    • Bridges represent critical pathways for novel information diffusing between separate social clusters.
  • Local Bridge:
    • An edge that, if removed, does not necessarily disconnect the entire graph, but significantly increases the shortest path length between its end nodes.
    • Local bridges act as shortcuts that facilitate efficient, cross-group communication.

Local Bridge: A Visual Example

  • Let’s look at the edge C-D highlighted in red:
    • It connects the left cluster \(\{A, B, C\}\) to the right cluster \(\{D, E, F\}\).
  • Is it a bridge? No. If removed, the graph remains connected via the bottom path (\(B-G-H-I-E\)).
  • Is it a local bridge? Yes!
    • Observed distance: \(d(C, D) = 1\).
    • If removed, the distance increases to: \[d(C, D) = 5 \quad (C-B-G-H-I-E-D)\]

Vertex Deletion & Node Connectivity

  • We can also disconnect a graph by removing nodes (vertices).
  • Removing a node also removes all edges incident to it—nodes “take their links with them”!
  • Consequently, it is often much easier to disrupt or disconnect a network by removing key intermediate nodes than by removing edges.
  • Node Cutset (Vertex Cutset):
    • The minimum set of nodes whose removal disconnects the graph (or a specific pair of non-adjacent nodes \(u, v\)).
  • Nodes in the cutset represent critical brokerage or “connector” positions.

Edge Cutset: A Visual Example

  • An edge cutset is a set of edges whose removal disconnects the graph.
  • In our house graph on the right, the edges C-A and D-A are highlighted in red.
  • Removing both edges completely disconnects node \(A\) from the rest of the network.
  • This is a valid edge cutset of size 2.

Node Cutset: A Visual Example

  • A node cutset is a set of nodes whose removal disconnects the graph.
  • In our house graph on the right, node E is highlighted in red.
  • Removing node E (which also removes all of its incident edges: \(B-E, E-C, E-D\)) completely disconnects node \(B\) from the rest of the network.
  • This is a minimum node cutset of size 1 (Node \(E\) is a cutpoint or articulation point).

K-Connected Graphs

  • A graph is \(k\)-connected (or \(k\)-node connected) if the minimum number of nodes required to disconnect it is \(k\):
    • 1-Connected: Removing 1 node can disconnect the graph (contains an articulation point or cutpoint).
    • 2-Connected: Requires removing at least 2 nodes to disconnect it.
    • 3-Connected: Requires removing at least 3 nodes to disconnect it.
  • Higher \(k\)-connectivity indicates a more robust, cohesive, and redundant network.

1-Connected Graph: Vulnerable Structure

Before (Star Graph)

After (Removing Node A)

  • 1-Connected: Only requires removing \(k=1\) node to disconnect the graph.
  • Node A is the articulation point (cutpoint). Removing it isolates nodes B, C, and D.

2-Connected Graph: Moderate Redundancy

Before (Ring Graph)

After (Removing Nodes A and C)

  • 2-Connected: Requires removing \(k=2\) nodes to disconnect the graph.
  • Removing only \(1\) node (e.g. A) leaves a connected path (D-C-B), so it does not disconnect the graph.
  • Removing \(2\) nodes (e.g. A and C) breaks the ring, completely isolating nodes B and D.

3-Connected Graph: High Cohesion

Before (Wheel Graph)

After (Removing Nodes A, B, and D)

  • 3-Connected: Requires removing \(k=3\) nodes to disconnect the graph.
  • Removing \(1\) or \(2\) nodes (e.g. A and B) still leaves path E-D-C connected, meaning it remains connected.
  • Removing \(3\) nodes (e.g. Center A and opposite base nodes B and D) isolates C and E.

Graph Cutsets: Quantitative Cohesion

  • Cohesion can be directly translated to graph-theoretic cutsets:
    • Cohesive Groups: Have large edge-cutsets and node-cutsets. Many connections or individuals must be removed to disrupt or fragment the group.
    • Fragmented Groups: Have small cutsets (such as bridges or single cutpoints). They are vulnerable to rapid disruption if key facilitators are removed.
  • Any network can be decomposed into hierarchical subgraphs with specific levels of \(k\)-connectivity.

Menger’s Theorem

  • A foundational result in graph theory proposed by Karl Menger (1927):
    • Menger’s Theorem: If a graph is \(k\)-connected, there are at least \(k\) node-independent paths (paths that do not share any common inner nodes) connecting each non-adjacent pair of vertices.
  • Sociological Implication:
    • In a 3-connected cohesive subgroup, any two non-adjacent members are connected in at least three separate, independent ways.
    • This ensures highly redundant, reliable information flow that cannot be blocked by a single broker!

Part 5: Directed Connectivity & Matrices

The Reachability Matrix (\(D_r\))

Directed Graph

Reachability Matrix (\(D_r\))

A B C D E
A – 0 1 1 1
B 0 – 0 1 1
C 0 0 – 1 1
D 0 0 0 – 0
E 0 0 0 1 –
  • Definition: \(D_r(i,j) = 1\) if node \(i\) can reach node \(j\) via a path of any length (\(0\) otherwise).
  • Examples:
    • \(A\) can reach \(E\) via path \(A \rightarrow C \rightarrow E\), so \(D_r(A, E) = 1\).
    • \(B\) cannot reach \(A\), so \(D_r(B, A) = 0\).

Matrix Row & Column Patterns

The reachability matrix reveals structural node behaviors:

  • Receiver Nodes:
    • Have all zeros in their corresponding row of \(D_r\) (cannot reach anyone, e.g. Node \(D\) above).
  • Transmitter Nodes:
    • Have all zeros in their corresponding column of \(D_r\) (cannot be reached by anyone, e.g. Node \(A\) or \(B\) or \(C\) above).

Flavors of Connectivity in Directed Graphs

Because of edge directionality, directed graphs have three distinct levels of connectivity:

  1. Strongly Connected:
    • Every pair of nodes is mutually reachable via directed paths.
  2. Unilaterally Connected:
    • Every pair of nodes is connected by at least one directed path (from \(u \rightarrow v\) OR \(v \rightarrow u\), but not necessarily both).
  3. Weakly Connected:
    • Every pair of nodes is connected by at least a semipath (connected if we ignore arrow directions).

Reachability and Connectivity Types

The reachability matrix reveals the global connectivity type of the digraph:

  • Strongly Connected:
    • The reachability matrix is the all-ones matrix (excluding diagonal). Every node can reach every other node.
  • Unilaterally Connected:
    • The matrix contains some zeros, but for any pair, either \(D_r(i,j) = 1\) or \(D_r(j,i) = 1\). There are no mutually unreachable pairs.
  • Weakly Connected:
    • Contains at least one pair of nodes that are mutually unreachable (\(D_r(i,j) = 0\) AND \(D_r(j,i) = 0\), e.g., Nodes \(A\) and \(E\) are mutually unreachable in a weak graph).

Graph Connectedness (\(C\)): Concept

  • Graph Connectedness (\(C\)) measures the extent to which a network approaches the ideal where everyone can reach everyone else.
  • Mathematically, it is the density of the directed reachability matrix (\(D_r\)): \[C = \frac{\sum_{i \neq j} D_r(i,j)}{n(n-1)}\]
    • Where the numerator is the sum of all ones in the reachability matrix (excluding the diagonal).
    • The denominator \(n(n-1)\) is the total possible off-diagonal cells (all possible paths).
  • It ranges from \(0\) (completely disconnected) to \(1.0\) (strongly connected, where everyone can reach everyone).

Graph Connectedness (\(C\)): Example

Directed Graph

Reachability Matrix (\(D_r\))

A B C D E
A – 0 1 1 1
B 0 – 0 1 1
C 0 0 – 1 1
D 0 0 0 – 0
E 0 0 0 1 –
  • Step-by-Step Calculation:
    • Sum of ones in our reachability matrix (\(D_r\)): \(3 \text{ (Row A)} + 2 \text{ (Row B)} + 2 \text{ (Row C)} + 0 \text{ (Row D)} + 1 \text{ (Row E)} = 8\).
    • Total possible connections: \(n(n-1) = 5(4) = 20\).
    • Connectedness: \(C = \frac{8}{20} = 0.40 \quad (40\%)\).

The Geodesic Distance Matrix (\(D_g\))

  • The geodesic distance matrix (\(D_g\)) records the length of the shortest path (geodesic) connecting each pair of nodes.
  • Rules:
    • Adjacent nodes get a distance of \(1\).
    • Non-adjacent nodes get the length of their shortest path.
    • Unconnected nodes (unreachable) get a distance of infinity (\(\infty\) or Inf).
  • In undirected graphs, \(D_g\) is symmetric. In directed graphs, \(D_g\) is asymmetric.

Node Eccentricity & Graph Diameter

From the geodesic distance matrix, we extract several fundamental whole-graph metrics:

  • Node Eccentricity: The maximum geodesic distance from a focal node to any other reachable node in the graph.
  • Graph Diameter (\(d\)): The maximum geodesic distance across all pairs of connected nodes (longest shortest path).
    • For our undirected graph, \(d = 3\).

Conclusion & Core Takeaways

  • Indirect connection is the engine of diffusion:
    • Paths trace how resources, information, and influence flow through networks.
  • Directed path flows are asymmetric:
    • Edge directions create unequal access, where some nodes can reach everyone, but are completely unreachable themselves.
  • Matrices provide global signatures:
    • The reachability matrix (\(D_r\)) and the distance matrix (\(D_g\)) let us calculate connectedness, diameter, and eccentricity, transforming qualitative network structures into rigorous quantitative indices.
