Interactive Network Binarization Dashboard

Play with Thresholds in Real-Time

This interactive dashboard allows students to explore the concept of network binarization (as discussed in the Adjacency Matrix chapter) in real-time.

Adjust the slider below to change the threshold cutoff (\(\Theta\)). Any tie with a weight strictly greater than the threshold (\(W_{ij} > \Theta\)) becomes an active binary tie (\(1\)), while weaker ties are pruned (\(0\)).

Step 1: Adjust the Binarization Threshold

viewof theta = Inputs.range([0, 10], {value: 3, step: 1, label: html`<b>Threshold Cutoff (θ):</b>`})

1. Weighted Matrix (\(\mathbf{W}\))

This matrix records the exact volume of communication (e.g., messages per day) between actors.

html`
<table class="table table-bordered table-striped" style="text-align: center; font-family: sans-serif; font-size: 15px;">
  <thead>
    <tr style="background-color: #343a40; color: white;">
      <th></th>
      ${labels.map(l => html`<th>${l}</th>`)}
    </tr>
  </thead>
  <tbody>
    ${labels.map((l, i) => html`
      <tr>
        <th style="background-color: #343a40; color: white;">${l}</th>
        ${weightedMatrix[i].map((v, j) => {
          const isActive = v > theta && i !== j;
          return html`
            <td style="background-color: ${isActive ? '#ffdfc4' : '#f8f9fa'}; 
                       color: ${i === j ? '#6c757d' : 'black'};
                       font-weight: ${isActive ? 'bold' : 'normal'};
                       border: ${isActive ? '2px solid #ff7e26' : '1px solid #dee2e6'};">
              ${i === j ? '--' : v}
            </td>
          `;
        })}
      </tr>
    `)}
  </tbody>
</table>
`

2. Binarized Matrix (\(\mathbf{A}\))

Formed by setting cell \(A_{ij} = 1\) if \(W_{ij} > \theta\), else \(0\). Active cells are highlighted.

html`
<table class="table table-bordered" style="text-align: center; font-family: sans-serif; font-size: 15px;">
  <thead>
    <tr style="background-color: #212529; color: white;">
      <th></th>
      ${labels.map(l => html`<th>${l}</th>`)}
    </tr>
  </thead>
  <tbody>
    ${labels.map((l, i) => html`
      <tr>
        <th style="background-color: #212529; color: white;">${l}</th>
        ${binarizedMatrix[i].map((v, j) => {
          const isDiagonal = i === j;
          return html`
            <td style="background-color: ${isDiagonal ? '#f8f9fa' : (v === 1 ? '#ff7e26' : '#ffffff')}; 
                       color: ${isDiagonal ? '#6c757d' : (v === 1 ? 'white' : '#ced4da')}; 
                       font-weight: ${v === 1 ? 'bold' : 'normal'};">
              ${isDiagonal ? '--' : v}
            </td>
          `;
        })}
      </tr>
    `)}
  </tbody>
</table>
`

3. Binarized Graph

Solid blue lines represent ties that “survive” the threshold. Light dashed lines show pruned ties.

svg`
<svg width="400" height="350" style="background: #f8f9fa; border: 1px solid #dee2e6; border-radius: 4px;">
  <!-- Draw all potential ties first as light gray dashed lines -->
  ${weightedMatrix.flatMap((row, i) => 
    row.map((val, j) => {
      if (i >= j || val === 0) return null;
      const n1 = nodeCoords[i];
      const n2 = nodeCoords[j];
      const isActive = val > theta;
      return svg`
        <line x1="${n1.x}" y1="${n1.y}" x2="${n2.x}" y2="${n2.y}" 
              stroke="${isActive ? '#1f77b4' : '#dee2e6'}" 
              stroke-width="${isActive ? '4' : '1'}"
              stroke-dasharray="${isActive ? '0' : '4,4'}" />
              
        <!-- Weight label in middle of line -->
        <rect x="${(n1.x + n2.x)/2 - 8}" y="${(n1.y + n2.y)/2 - 8}" width="16" height="16" fill="white" opacity="0.8" rx="3" />
        <text x="${(n1.x + n2.x)/2}" y="${(n1.y + n2.y)/2 + 4}" 
              font-family="sans-serif" font-size="10px" font-weight="bold"
              fill="${isActive ? '#1f77b4' : '#adb5bd'}" text-anchor="middle">
          ${val}
        </text>
      `;
    })
  )}

  <!-- Draw nodes on top of lines -->
  ${nodeCoords.map(node => svg`
    <circle cx="${node.x}" cy="${node.y}" r="18" fill="#ff7e26" stroke="white" stroke-width="2" />
    <text x="${node.x}" y="${node.y + 5}" font-family="sans-serif" font-size="13px" font-weight="bold" fill="white" text-anchor="middle">
      ${node.name}
    </text>
  `)}
</svg>
`

Data and Calculations Setup

The interactive computations above are run client-side in your browser using Observable JS (OJS), which means they are fully active in statically compiled HTML pages without requiring an R or Python server!

// The weighted adjacency matrix
weightedMatrix = [
  [0, 8, 2, 1, 0, 0],
  [8, 0, 9, 3, 1, 0],
  [2, 9, 0, 7, 0, 0],
  [1, 3, 7, 0, 5, 0],
  [0, 1, 0, 5, 0, 6],
  [0, 0, 0, 0, 6, 0]
]
weightedMatrix = [
  [0, 8, 2, 1, 0, 0],
  [8, 0, 9, 3, 1, 0],
  [2, 9, 0, 7, 0, 0],
  [1, 3, 7, 0, 5, 0],
  [0, 1, 0, 5, 0, 6],
  [0, 0, 0, 0, 6, 0]
]

labels = ["A", "B", "C", "D", "E", "F"]

// Dynamic calculation of binary adjacency matrix
binarizedMatrix = weightedMatrix.map(row => row.map(v => v > theta ? 1 : 0))

// Fixed coordinates for clean, stable layout
nodeCoords = [
  {x: 100, y: 80, name: "A"},
  {x: 200, y: 50, name: "B"},
  {x: 300, y: 100, name: "C"},
  {x: 300, y: 220, name: "D"},
  {x: 200, y: 280, name: "E"},
  {x: 100, y: 200, name: "F"}
]
