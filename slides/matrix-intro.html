Networks, Graphs, and Matrices

An Introduction to Relationship Matrices

Part 1: Social Networks, Graphs, and Matrices

Representing Social Networks

  • How do we describe and analyze social networks? We use three distinct levels of abstraction:
    1. Social Networks (Real Life): Intuitive, fuzzy concepts based on natural language and daily interactions (e.g., popularity, friendship, reciprocity).
    2. Graphs (Mathematical Model): Pictorial representation where actors are points (vertices/nodes) and relations are lines (edges/ties/links).
    3. Matrices (Quantitative Tool): Two-dimensional arrays of numbers used to perform mathematical operations and calculations.
  • While graphs are intuitive for small groups, they quickly become unreadable “hairballs” as networks grow.
  • Matrices give us the analytical leverage to calculate precise network metrics.

The SNA “Three-Step Shuffle”

  • To build rigorous, scientific measures, network analysts perform a three-step shuffle:
  • Step 1: The Social-Theoretic Level
    • Grab an “off-the-shelf” fuzzy concept from social science (e.g., popularity).
  • Step 2: The Graph-Theoretic Level
    • Translate the concept into formal graph theory (e.g., indegree—the number of directed edges pointing to a node).
  • Step 3: The Matrix-Algebraic Level
    • Link the graph concept to matrix algebra to perform mathematical operations (e.g., column sum of the adjacency matrix).

The Shuffle in Action: Popularity

  • Step 1 (Theory):
    • Popularity is “being highly liked or nominated by peers.”
  • Step 2 (Graph):
    • We model the students as vertices (\(V\)) and nominations as directed edges (\(E\)).
    • Popularity becomes indegree centrality (\(d_{in}(v)\)).
  • Step 3 (Matrix):
    • We represent the network as a directed adjacency matrix (\(\mathbf{A}\)).
    • The indegree of node 3 is obtained by summing the elements in the 3rd column:
    • \[d_{in}(v_j) = \sum_{i} A_{ij}\]

Don’t Confuse Them!

Part 2: Introduction to Matrices

What is a Matrix?

  • Invented for social networks by Elaine Forsyth and Leo Katz in the mid-1940s.
  • A matrix is a two-dimensional array of numbers organized into rows (\(R\)) and columns (\(C\)).
  • Dimensions:
    • Described as \(R \times C\) (rows always come first, columns second).
    • e.g., a \(5 \times 3\) matrix has 5 rows and 3 columns.
  • Rectangular Matrices:
    • \(R \neq C\) (e.g., attribute-value matrices, spreadsheet data, or actor-by-event affiliation networks).

Matrix Indexing and Cells

  • The intersection of row \(i\) and column \(j\) defines a cell in the matrix.
  • Notation:
    • We use boldfaced capital letters to name matrices (e.g., matrix \(\mathbf{A}\)).
    • We use lowercase, indexed letters to refer to individual cell values: \(a_{ij}\) (Value in Row \(i\), Column \(j\)).
    • Row index is \(i\); column index is \(j\).
  • For example, if \(\mathbf{B}\) is a survey matrix:
    • Cell \(b_{32}\) refers to Row 3 (Case 3, a person) and Column 2 (Attribute 2, e.g., Age).
    • If that person is 54 years old, then \(b_{32} = 54\).

Relationship Matrices

  • Social network analysis rarely uses general attribute-value matrices.
  • Instead, we use Relationship Matrices:
    • The same list of cases (actors) is listed on both rows and columns.
    • Cell \(a_{ij}\) records the value of the relationship from row actor \(i\) to column actor \(j\).
    • All relationship matrices are Square Matrices:
      • The number of rows equals the number of columns (\(R = C\)).
      • A square matrix of size \(N\) is said to be of order \(N\).

Diagonal vs. Off-Diagonal Cells

  • The Main Diagonal:
    • The diagonal line running from the top-left to the bottom-right corner.
    • Composed of cells where row index equals column index (\(i = j\)).
    • Represents the relationship of actors with themselves (\(a_{ii}\)), which we typically ignore by blocking the diagonals with a dash (--).
  • Off-Diagonal Cells (\(i \neq j\)):
    • Upper Triangle (\(i < j\)): Cells above the main diagonal (e.g., \(a_{12}, a_{13}\)).
    • Lower Triangle (\(i > j\)): Cells below the main diagonal (e.g., \(a_{21}, a_{31}\)).

  • Symmetric ties (undirected graphs) mean the upper and lower triangles are identical (\(V_1 = V_3\), \(V_2 = V_5\)).
  • Asymmetric ties (directed graphs) do not require symmetry.

Part 3: The Adjacency Matrix

Defining Adjacency in Matrices

  • The Adjacency Matrix is the most important representation of a network.
  • It is a binary relationship matrix of order \(N\) indicating whether pairs of nodes are directly connected (adjacent) in the graph.
  • Formal Definition:
    • \[A_{ij} = 1 \quad \text{if edge } \{v_i, v_j\} \text{ exists in } E\]
    • \[A_{ij} = 0 \quad \text{if edge } \{v_i, v_j\} \text{ does not exist in } E\]
  • In simple graphs, we always set \(A_{ii} = 0\) (or --) to block self-loops.

Symmetric Adjacency Matrices (Undirected Graphs)

  • Undirected graphs feature symmetric ties (e.g., co-workers).
  • Resulting adjacency matrix is symmetric:
    • Flipped along the diagonal, the upper and lower triangles are mirror images.
    • \[A_{ij} = A_{ji} \quad \text{for all } i, j\]

Asymmetric Adjacency Matrices (Directed Graphs)

  • Directed graphs feature asymmetric ties (e.g., advice, liking).
  • Resulting adjacency matrix is asymmetric:
    • The upper and lower triangles do not mirror each other.
    • \(A_{ij} \neq A_{ji}\) is common (unreciprocated ties).

Part 4: Advanced Adjacency Matrices

Weighted Adjacency Matrices

  • In real-world social life, ties are rarely just binary (\(0\) or \(1\)); they have varying degrees of strength or intensity.
  • Weighted Graphs:
    • Associate numerical values with edges (e.g., emails sent per day, dollars traded, papers co-authored).
    • Cell entries represent real numbers: \(W_{ij} = w\) (where \(w\) is the tie weight).
  • Binarization:
    • To simplify a dense weighted matrix (\(\mathbf{W}\)), we apply a threshold cutoff \(\Theta\):
    • \[A_{ij} = 1 \quad \text{if } W_{ij} > \Theta\]
    • \[A_{ij} = 0 \quad \text{if } W_{ij} \le \Theta\]

Multiplexity and Multigraphs

  • In social networks, actors often share multiple types of relationships (e.g., being co-workers, friends, and neighbors simultaneously). This is called multiplexity.
  • A network with multiple distinct types of edges between nodes is a multigraph.
  • Matrix Representation:
    • A single cell can only hold one value, so we cannot represent a multigraph in a single standard 2D matrix.
    • Instead, we represent it as a set of stacked adjacency matrices:
      • Matrix \(\mathbf{A}^{(1)}\) (Kinship), Matrix \(\mathbf{A}^{(2)}\) (Advice), Matrix \(\mathbf{A}^{(3)}\) (Friendship).
    • This stacked array forms a three-dimensional matrix (or tensor) of dimensions \(N \times N \times K\).

Bipartite Matrices (Two-Mode Networks)

  • Two-Mode Networks:
    • Map connections between actors and groups/events/organizations (e.g., executives sitting on boards of directors, activists co-attending protests).
  • Bipartite Graphs:
    • Feature two disjoint sets of vertices (\(N\) actors and \(M\) events). Edges only link actors to events, never actors to actors or events to events.
  • Affiliation Matrix (\(\mathbf{C}\)):
    • Because the vertex sets are disjoint, this is represented as a rectangular matrix of dimensions \(N \times M\).
    • \(C_{ij} = 1\) if actor \(i\) is affiliated with event \(j\), else \(0\).

Part 5: Summary & Key Takeaways

Summary of Key Concepts

  • Matrices provide analytical power:
    • Eyeballing “hairball” graphs gets impossible as networks scale. Matrices allow computer systems to easily run computations.
  • Adjacency Matrix:
    • Stores direct connections. Symmetric (\(A_{ij} = A_{ji}\)) for undirected graphs; asymmetric (\(A_{ij} \neq A_{ji}\)) for directed graphs.
  • Main Diagonal:
    • Represents self-loops (\(i = j\)), which we block (--) in simple graphs.
  • Weighted & Multigraph Matrices:
    • Weighted matrices record tie strengths (which can be binarized using \(\Theta\)). Multigraphs represent multiplex ties using stacked 3D matrices (tensors).
  • Affiliation Matrices:
    • Bipartite graphs represent two-mode networks using rectangular \(N \times M\) matrices.
