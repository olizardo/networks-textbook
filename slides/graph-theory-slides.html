Graph Theory

The Basics of Social Network Analysis

Introduction to Graphs

What is a Graph?

  • A graph (\(G\)) is an abstract mathematical object consisting of two main parts:
  • A vertex set, \(V\), which contains all the nodes (actors) in the network.
    • e.g., \(V = \{A, B, C, D\}\)
  • An edge set, \(E\), which contains all the ties (relationships) between the nodes.
    • e.g., \(E = \{AB, AC\}\)
  • Together, they define the graph: \(G = \{V, E\}\)

The Building Blocks: Nodes

  • In social networks, nodes represent the actors
    • Usually drawn as circles or points in a diagram
    • Often individuals (people) or organizations (groups, companies)
  • In wider applications of network science:
    • Nodes can represent any entities in a system
    • Examples: power generation stations, proteins, websites

The Building Blocks: Edges

  • Edges represent a connection or a social tie between two nodes
    • Can be a permanent relationship (e.g., “brother of”)
    • Or a fleeting interaction (e.g., a text message, co-presence)
  • In set theory:
    • The set of edges is a collection of pairs of nodes
    • If node \(A\) is linked to node \(B\), then \(AB \in E\) (or written as \(V_A V_B\))

Edges as Channels

  • Edges act as channels for flows of content:
    • Positive/Neutral: influence, advice, information, support, power, traffic
    • Negative: disease, bullying, gossip, conflict

What is a Graph? (An Example) (1)

  • Let’s define a graph \(G\) with 4 nodes (\(A, B, C, D\)) and 2 edges (\(AB, AC\)):
    • \(V = \{A, B, C, D\}\)
    • \(E = \{AB, AC\}\)
    • \(G = \{V, E\}\)
  • The cardinality (number of members in a set) is denoted by \(|N|\):
    • Vertex set cardinality: \(|V| = n = 4\)
    • Edge set cardinality: \(|E| = m = 2\)

What is a Graph? (An Example) (2)

  • This graph can be represented by the signature \(G(n, m) = G(4, 2)\)
  • Note the lack of edges:
    • No edge between \(B\) and \(C\) means no relationship between them.
    • Node \(D\) is not connected to any other node.

Variations of \(G(4, 2)\)

  • The signature \(G(4, 2)\) (4 nodes, 2 edges) does not uniquely define a single graph.
  • It can describe multiple topologically distinct graphs.

Graph Labeling

  • Labeled Graphs:
    • Distinctions are made between nodes (e.g., A, B, C are different people).
    • Graph is defined by its specific structural representation (e.g., the last graph in the previous slide).
  • Unlabeled Graphs:
    • Nodes are interchangeable or anonymous.
    • The focus is only on the abstract structure of connections.

Trivial Graphs

  • Trivial Graph:
    • A \(G(1, 0)\) graph: a single isolated node with zero connections.
    • Social equivalent: An isolated person with no connections (e.g., the Japanese Hikikomori).

Non-Trivial Graphs

  • Non-Trivial Graphs:
    • Any graph larger than \(G(1, 0)\) used for social network analysis.
    • Connected Dyad: The \(G(2, 1)\) graph. Two nodes connected by a single link. The “hydrogen atom” of society.
    • Disconnected Dyad: A \(G(2, 0)\) graph. Two nodes with no link (e.g., two people on a deserted island not speaking).

Basic Graph Properties

  • Adjacent: Joined by an edge (e.g., \(A\) and \(B\)).
  • Nonadjacent: Not joined by an edge (e.g., \(A\) and \(C\)).
  • Isolate: Node with zero incident edges (e.g., \(D\)).
  • Incident: An edge “touches” a node (e.g., edge \(AB\) is incident on \(A\)).
  • End Vertices: Nodes at the ends of an edge (e.g., \(A\) and \(B\) for edge \(AB\)).

The Graph Complement

  • The complement (\(G'\)) of a graph \(G\) contains an edge between two nodes if and only if they are disconnected in \(G\).
  • It represents the “negative” of the original graph, showing all the ties that could exist but don’t.

Simple Graphs

  • Most social networks are represented as simple graphs.
  • A graph is simple if it meets two requirements:
    1. No Multiple Edges: Only one edge can join any pair of nodes (unlike \(A\) and \(B\)).
    2. No Loops: No edges connect a node to itself (unlike node \(C\)).
  • Loops and multiple edges do not make sense for most typical sociological applications.

Graphs are Not Pictures!

  • Do not confuse a mathematical “graph” (a set of two sets) with its “drawing” (a point and line plot).
  • The same graph can have many different, and even misleading, drawings.
  • The drawing is just a visual aid; the underlying structure is what matters.

Graphs and Subgraphs

Graphs and Subgraphs

  • Sometimes we are interested in analyzing only some parts of a whole network.
  • A subgraph \(G' = \{V', E'\}\) is a subset of the original graph \(G = \{V, E\}\), which is written as \(G' \subset G\):
    • The node set \(V'\) is a subset of \(V\) (\(V' \subset V\)).
    • The edge set \(E'\) is a subset of \(E\) (\(E' \subset E\)).
    • Edges in the subgraph must have both endpoints in the node subset \(V'\).

Vertex-Induced Subgraphs

  • A vertex-induced subgraph is created by selecting a subset of nodes (\(V' \subset V\)) and including all the edges from the original graph that connect nodes within that subset.
  • This is the most common method for creating subgraphs in social network analysis.

Vertex-Deleted Subgraphs (1)

  • We define a subgraph by deleting nodes: \(G' = G - \{a, b, c\}\), where \(\{a, b, c\}\) is the set of nodes being deleted.
  • CRITICAL RULE: When you delete nodes, all edges incident to those nodes are automatically removed as well.
  • For example, deleting \(\{F, G, H, I, J\}\) from our 10-node graph yields the subgraph on the right.
  • This shows that a vertex-deleted subgraph can be equivalent to a vertex-induced subgraph on the remaining nodes (here, \(\{A, B, C, D, E\}\)).

Vertex-Deleted Subgraphs (2)

  • Two special cases of vertex deletion are:
    • Null Graph: The subgraph that results from removing all nodes from the original graph.
    • Singleton Graph (or Trivial Graph): The subgraph that results from removing all nodes except for one.

Edge-Deleted Subgraphs

  • We define a subgraph by removing edges: \(G' = G - \{e_1, e_2, ...\}\), where \(\{e_1, e_2, ...\}\) is the set of edges being deleted.
  • CRITICAL RULE: When you delete edges, the nodes that were connected by those edges remain in the graph.
  • Spanning Subgraph: A subgraph created by removing only edges while leaving all original nodes intact.
  • Empty Graph: A special case of edge deletion that results from removing all edges from the original graph, leaving only the set of isolated nodes.
  • The example on the right removes the six edges \(\{AB, AE, AC, CI, CE, GJ\}\); notice all 10 nodes remain!

Special Subgraphs: Ego Graph

  • Ego Graph: A special type of subgraph defined by picking a central node (ego) and the nodes that are connected to it, along with the edges connecting those nodes.
  • The central node’s adjacent contacts are called its alters.
  • Ego graphs are particularly useful for analyzing social networks at the level of individual actors.

Vertex Fusion (1)

  • We can construct a new graph from a graph by fusing two vertices.
  • Vertex Fusion:
    • Replace two original vertices with a single vertex.
    • Keep the combined adjacency relations of both original vertices.

Vertex Fusion (2)

  • Vertex fusion is useful in social network analysis for:
    • Collapsing equivalence classes.
    • Analyzing blockmodels.
    • Merging groups or roles.

Set Operations on Graphs: Union

  • Because graphs are defined as sets, we can perform standard set operations on them.
  • Union (\(\cup\)): Combine the vertices and edges of two graphs.
    • \(V(G_1 \cup G_2) = V(G_1) \cup V(G_2)\)
    • \(E(G_1 \cup G_2) = E(G_1) \cup E(G_2)\)

Set Operations on Graphs: Intersection

  • Intersection (\(\cap\)): Keep only the vertices and edges present in both graphs.
    • \(V(G_1 \cap G_2) = V(G_1) \cap V(G_2)\)
    • \(E(G_1 \cap G_2) = E(G_1) \cap E(G_2)\)

Node Neighborhoods

Node Neighborhoods

  • Neighborhood (\(\mathcal{N}(v)\)):
    • The set of nodes that are directly connected (adjacent) to node \(v\).
    • These are a node’s immediate neighbors.
    • Isolates have an empty neighborhood set (\(\emptyset\)).
  • Example: \(\mathcal{N}(A) = \{B, C, D, F, H\}\)

Neighborhood Intersection

  • Neighborhood Intersection (\(\mathcal{N}(u) \cap \mathcal{N}(v)\)) is the set of common neighbors connected to both \(u\) and \(v\).
  • In our graph:
    • \(N(1) = \{3\}\)
    • \(N(4) = \{3, 7\}\)
  • The intersection is the single node they share:
    • \(N(1) \cap N(4) = \{3\}\)

Neighborhood Union

  • Neighborhood Union (\(\mathcal{N}(u) \cup \mathcal{N}(v)\)) is the set of all nodes connected to either \(u\) or \(v\).
  • In our graph:
    • \(N(1) = \{3\}\)
    • \(N(4) = \{3, 7\}\)
  • The union contains all unique neighbors from both sets:
    • \(N(1) \cup N(4) = \{3, 7\}\)

Directed Graph Elements & Metrics

Neighborhoods in Directed Graphs (1)

  • Because links are directional, nodes have two neighborhoods.
  • In-Neighborhood (\(N^{in}(v)\)):
    • Set of source nodes pointing to \(v\).
    • Example: \(N^{in}(D) = \{B, E, G\}\).

Neighborhoods in Directed Graphs (2)

  • Out-Neighborhood (\(N^{out}(v)\)):
    • Set of destination nodes that \(v\) points to.
    • Example: \(N^{out}(B) = \{A, C, D\}\).
  • A node appears in both neighborhoods only if there is a reciprocal tie.

Node Degree

Node Degree in Undirected Graphs

  • A node’s degree (\(k_i\)) is the number of edges incident on it.
  • It is the cardinality (size) of a node’s neighborhood: \(k_i = |\mathcal{N}(i)|\).
  • Sociological meaning: Popularity, Influence, or Centrality.

Node Degree in Directed Graphs: Indegree

  • Directed graphs have two distinct degrees for each node.
  • Indegree (\(k^{in}_i\)):
    • Number of edges pointing to node \(i\) (cardinality of \(N^{in}(i)\)).
    • Sociological meaning: Popularity, Prestige, or Status.

Node Degree in Directed Graphs: Outdegree

  • Outdegree (\(k^{out}_i\)):
    • Number of edges pointing from node \(i\) (cardinality of \(N^{out}(i)\)).
    • Sociological meaning: Sociability or Activity.

Basic Graph Metrics

Graph Order and Size (1)

  • Graph Order (\(n\)):
    • The number of nodes in the graph (\(n = |V|\)).
    • Cardinality of the vertex set.
  • Graph Size (\(m\)):
    • The number of edges in the graph (\(m = |E|\)).
    • Cardinality of the edge set.

Graph Order and Size (2)

  • In our undirected graph (10 nodes, 20 edges): \(n = 10\), \(m = 20\).
  • In our directed graph (7 nodes, 11 edges): \(n = 7\), \(m = 11\).

Graph Maximum Size

  • The maximum size of a simple graph of order \(n\) is the number of edges in a complete graph (where every node is connected to every other node).
  • Undirected: \(Max(E) = \frac{n(n - 1)}{2}\)
  • Directed: \(Max(E) = n(n - 1)\)

Graph Density

  • Density (\(d\)) is the ratio of the observed number of edges (\(m\)) to the maximum possible number of edges.
  • It’s a value between 0 (empty) and 1 (complete).
  • Undirected: \(d = \frac{2m}{n(n-1)}\)
  • Directed: \(d = \frac{m}{n(n-1)}\)
  • It can be interpreted as the probability that any two randomly chosen nodes are connected.
  • Denser networks are less vulnerable to breakdowns when key nodes are removed.

Degree-Based Graph Metrics

Graph Degree Set and Sequence

  • Graph Degree Set: A list of the degrees of every node in the graph.
  • Graph Degree Sequence: The degree set sorted in descending order.
  • This provides a “fingerprint” of the graph’s overall connectivity structure.

Degree Range & Sum

  • Maximum Degree (\(k_{max}\)) and Minimum Degree (\(k_{min}\)).
  • Degree Range (\(k_r\)): \(k_{max} - k_{min}\).
  • Sum of Degrees (\(\sum k_i\)):
    • In an undirected graph, this is always twice the number of edges: \(\sum k_i = 2m\).

Graphical Degree Sequences

  • A graphical degree sequence is a sequence of numbers that can be the degree sequence of a simple graph.
  • Not every sequence of integers is graphical.
  • Havel-Hakimi Theorem provides a recursive algorithm to check if a sequence is graphical.

Average Degree

  • Average Degree (\(\bar{k}\)): The average of all node degrees in the graph.

    \[\bar{k} = \frac{1}{n} \sum_{i=1}^{n} k_i = \frac{2m}{n}\]

  • It represents the expected degree of a randomly chosen node.

  • It is also directly related to density: \(\bar{k} = d(n-1)\).

Degree Variance

  • Degree Variance (\(\sigma^2_k\)): A measure of how much the node degrees vary from the average degree.

    \[\sigma^2_k = \frac{1}{n} \sum_{i=1}^{n} (k_i - \bar{k})^2\]

  • A low variance indicates a more homogeneous or uniform network (like a regular graph).

  • A high variance indicates a heterogeneous network with both low-degree nodes and high-degree “hubs” (like a scale-free network).

Regular Graphs

  • A regular graph is a graph where every node has the same degree.
  • This means the degree variance is zero.
  • These are often used as baseline models but are rare in real-world social networks.

Feld’s Friendship Paradox

  • Average Nearest Neighbor Degree (\(\bar{k}_{nn(i)}\)):
    • The average degree of node \(i\)’s neighbors: \[\bar{k}_{nn(i)} = \frac{1}{k_i} \sum_{j \in \mathcal{N}(i)} k_j\]
  • The Friendship Paradox (Scott Feld, 1991):
    • In almost all social networks, the average degree of a person’s friends (\(\bar{k}_{nn}\)) is greater than the average degree of the people in the network (\(\bar{k}\)).
    • Your friends have more friends than you do!

Directed Graph Elements & Metrics

Directed Degree Sets & Sequences

  • Directed graphs have two distinct degree sets (In-Degree set and Out-Degree set) and two distinct sequences.
  • Sum of Degrees:

    • The sum of in-degrees is always equal to the sum of out-degrees, which is equal to the size \(m\) (number of edges):

      \[\sum k^{in}_i = \sum k^{out}_i = m\]

    • Since both sum to \(m\), directed graphs have only one average degree: \(\bar{k} = m/n\).
