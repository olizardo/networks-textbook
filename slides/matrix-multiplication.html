Matrix Algebra in Social Networks: Part II

Multiplication, Conformability, and Applications (Paths & Walks)

Part 1: Conformability Rules

Standard Matrix Multiplication (\(\mathbf{A} \times \mathbf{B}\))

  • Unlike the element-wise Hadamard product, standard matrix multiplication is non-elementary.
  • It involves multiplying the rows of the left matrix by the columns of the right matrix.
  • Because rows and columns are matched, the sizes of the two multiplier matrices must follow a strict structural rule.
  • This rule is called Conformability.

The Conformability Rule

  • You can only multiply two matrices if the number of columns of the first matrix equals the number of rows of the second matrix.
  • Put their dimensions side-by-side:

\[\mathbf{A}_{3 \times \mathbf{5}} \times \mathbf{B}_{\mathbf{5} \times 6}\]

  • Inner Dimensions: The bold “fives” are the inner dimensions. They must be identical for the multiplication to be defined (conformable).
  • Outer Dimensions: The “three” and “six” are the outer dimensions. They dictate the size of the resulting product matrix:

\[\mathbf{A}_{3 \times \mathbf{5}} \times \mathbf{B}_{\mathbf{5} \times 6} = \mathbf{C}_{3 \times 6}\]

Clarification: Why Conformability Matters

When we compute cell \(c_{ij}\) in the product matrix, we: 1. Take Row \(i\) of the left matrix (which has as many elements as the left matrix has columns). 2. Take Column \(j\) of the right matrix (which has as many elements as the right matrix has rows). 3. Multiply element-by-element and sum.

For this to work, the row length and column length must match!

Example: - Row from \(\mathbf{A}\): 5 numbers - Column from \(\mathbf{B}\): 5 numbers - ✓ Can match them up and multiply.

If Column from \(\mathbf{B}\) had 7 numbers, we’d have a mismatch and can’t compute the sum.

Conformable vs. Non-Conformable

Conformable Example

  • Line up dimensions: \[\mathbf{A}_{4 \times \mathbf{2}} \times \mathbf{B}_{\mathbf{2} \times 3}\]
  • Inner dimensions match (2 = 2).
  • The multiplication is fully defined.
  • Product Matrix size: \[\mathbf{C}_{4 \times 3}\]

Non-Conformable Example

  • Line up dimensions: \[\mathbf{A}_{3 \times \mathbf{4}} \times \mathbf{B}_{\mathbf{2} \times 3}\]
  • Inner dimensions clash (4 \(\neq\) 2).
  • This operation is mathematically impossible.
  • The Visual Reason: When you try to dot-multiply a row of 4 by a column of 2, you “run out of numbers” on the right, making the sum undefined.

Matrix Multiplication is Non-Commutative

  • In scalar math, order doesn’t matter: \(4 \times 3 = 3 \times 4\).
  • In matrix algebra, order completely changes the structure:

\[\mathbf{A}_{2 \times \mathbf{3}} \times \mathbf{B}_{\mathbf{3} \times 2} = \mathbf{C}_{2 \times 2} \quad \text{(Square 2x2 Matrix)}\]

\[\mathbf{B}_{3 \times \mathbf{2}} \times \mathbf{A}_{\mathbf{2} \times 3} = \mathbf{D}_{3 \times 3} \quad \text{(Square 3x3 Matrix)}\]

  • Changing the multiplication order changes both the conformability checks and the resulting network’s dimensions!

Clarification: Non-Commutativity in Networks

Why does order matter socially?

  • \(\mathbf{A} \times \mathbf{B}\): “How many paths are there from ego to alter via intermediate nodes (using \(\mathbf{B}\)’s ties)?”
  • \(\mathbf{B} \times \mathbf{A}\): “How many paths via \(\mathbf{A}\)’s ties?” Different question, different answer, different matrix size.

This mirrors how network directionality and mediation structure change under different relationship sequences.

Conceptual Bridge: What Does Multiplication Mean in Networks?

Before diving into applications, step back:

  • In matrix multiplication, each cell \(c_{ij}\) of the product counts paths of a specific type connecting \(i\) to \(j\) through intermediate nodes.
  • The row-by-column multiplication is not arbitrary—it’s counting how many intermediate nodes \(k\) satisfy the path condition.
  • In network terms: “For each person \(k\) they both connect to, add 1 to their path count.”

This is the foundation for all dynamic network applications: common neighbors, clustering, walks, reachability.

Part 3: Dynamic Network Applications

Transpose Multiplication: Finding Common Neighbors

  • If we multiply a network’s adjacency matrix \(\mathbf{P}\) by its transpose \(\mathbf{P}^T\):

\[\mathbf{P} \times \mathbf{P}^T = \mathbf{C}_{\text{common}}\]

  • The rows of \(\mathbf{P}\) list each node’s friends; the columns of \(\mathbf{P}^T\) list them a second time
  • So each cell \(c_{ij}\) multiplies node \(i\)’s friendship list by node \(j\)’s — the result counts how much the two lists overlap: their common neighbors!
  • Our running example: six friends (A–F) and their “parties with” ties

Why Does \(\mathbf{P} \times \mathbf{P}^T\) Find Common Neighbors?

  • The Diagonal Cells (\(c_{ii}\)):
    • Multiplies Row \(i\) by Column \(i\) (which is Row \(i\) again in a symmetric matrix).
    • Result: \(\sum_k p_{ik} \times p_{ik} = \sum_k p_{ik}^2\). Since \(p_{ik} \in \{0,1\}\), this becomes \(\sum_k p_{ik}\) = the degree of node \(i\) (total friends).
  • The Off-Diagonal Cells (\(c_{ij}\)):
    • Multiplies Row \(i\) (node \(i\)’s friendships) by Column \(j\) of \(\mathbf{P}^T\) (which is Row \(j\), node \(j\)’s friendships).
    • Result: Counts exactly how many common neighbors node \(i\) and node \(j\) share (mutual friends).

  • Multiplying \(\mathbf{P} \times \mathbf{P}^T\) therefore compares every node’s friendship row with every other node’s friendship row

Application: Common Neighbors & Clustering

Why does this matter?

  • High common neighbors → likely future tie formation (Granovetter’s homophily).
  • Low common neighbors → structural hole (Burt’s brokerage).
  • Network clustering emerges from diagonal sums: nodes with many common neighbors form dense cliques.

Matrix Powers (\(\mathbf{P}^n\)) & Walks in Networks

  • Multiplying a square adjacency matrix by itself recursively reveals indirect connections (walks):
    • \(\mathbf{P}^2 = \mathbf{P} \times \mathbf{P}\)
    • \(\mathbf{P}^3 = \mathbf{P} \times \mathbf{P} \times \mathbf{P}\)
  • In network science, the entries of the \(n^{\text{th}}\) power of an adjacency matrix have a precise graph-theoretic meaning:
    • Off-Diagonal Cells (\(p^{n}_{ij}\)): Record the exact number of walks of length \(n\) connecting node \(i\) and node \(j\).
    • Diagonal Cells (\(p^{n}_{ii}\)): Record the exact number of closed walks (cycles) of length \(n\) starting and ending at node \(i\).

Clarification: Walks vs. Paths

  • Walk: A sequence of edges, allowing repetition of nodes and edges. Example: A→B→A→C (node A visited twice).
  • Path: A walk with no repeated nodes. Example: A→B→C (each node visited once).
  • Matrix powers count walks, not geodesic (shortest) paths.

For networks, walks reveal all indirect connections, not just optimal routes—important for diffusion, information flow, and redundancy.

Walks of Length 2 (\(\mathbf{P}^2\)): Setup & Intuition

  • To find walks of length 2, we square the adjacency matrix:

\[\mathbf{P}^2 = \mathbf{P} \times \mathbf{P}\]

  • Since \(\mathbf{P}\) is undirected, \(\mathbf{P}^T = \mathbf{P}\), making \(\mathbf{P}^2\) identical to \(\mathbf{P} \times \mathbf{P}^T\).
  • Therefore, walks of length 2 are mathematically equivalent to common neighbors!
  • Why? To go from \(i \rightarrow k \rightarrow j\) (walk of length 2), node \(k\) must be a common friend connected to both \(i\) and \(j\).

Walks of Length 2 (\(\mathbf{P}^2\)): Tracing Cell \(p^2_{\text{A, C}}\)

  • Let’s compute the number of walks of length 2 between Node A and Node C:
    • Row 1 (A): \(\color{red}{\{0, 1, 1, 0, 1, 0\}}\)
    • Column 3 (C): \(\color{blue}{\{1, 1, 0, 1, 1, 1\}}\)

\[p^2_{\text{A, C}} = (\color{red}{0} \times \color{blue}{1}) + (\color{red}{1} \times \color{blue}{1}) + (\color{red}{1} \times \color{blue}{0}) + (\color{red}{0} \times \color{blue}{1}) + (\color{red}{1} \times \color{blue}{1}) + (\color{red}{0} \times \color{blue}{1}) = \mathbf{2}\]

  • These two distinct walks of length 2 are:
    1. \(A \rightarrow \mathbf{B} \rightarrow C\) (via common friend B)
    2. \(A \rightarrow \mathbf{E} \rightarrow C\) (via common friend E)

Walks of Length 2 (\(\mathbf{P}^2\)): Tracing Diagonal Cell \(p^2_{\text{C, C}}\)

  • Let’s compute the diagonal cell \(p^2_{\text{C, C}}\) (Node C’s self-loop via 2-step walks):

\[p^2_{\text{C, C}} = (\color{red}{1} \times \color{blue}{1}) + (\color{red}{1} \times \color{blue}{1}) + (\color{red}{0} \times \color{blue}{0}) + (\color{red}{1} \times \color{blue}{1}) + (\color{red}{1} \times \color{blue}{1}) + (\color{red}{1} \times \color{blue}{1}) = \mathbf{5}\]

  • Walks of length 2 starting and ending at C are round-trips to each friend and back:
    • \(C \rightarrow A \rightarrow C\), \(C \rightarrow B \rightarrow C\), \(C \rightarrow D \rightarrow C\), \(C \rightarrow E \rightarrow C\), and \(C \rightarrow F \rightarrow C\).
  • Thus, the diagonal elements in \(\mathbf{P}^2\) represent the degrees of each node!

Application: Walks and Reachability

Why count walks?

  • Short walks (length 2–3) reveal local clustering and potential tie formation.
  • Longer walks identify reachable components and information-flow paths.
  • Comparing \(\mathbf{P}^n\) for different \(n\) shows how networks “thicken” or “thin” with distance.

Walks of Length 3 (\(\mathbf{P}^3\)) & Triangle Counting

  • To find walks of length 3, we multiply the squared matrix \(\mathbf{P}^2\) by the original matrix:

\[\mathbf{P}^3 = \mathbf{P}^2 \times \mathbf{P}\]

  • Diagonal cells (\(p^3_{ii}\)): Count length-3 cycles (triangles and longer cycles) starting and ending at node \(i\).
  • Since each triangle can be walked in two directions (clockwise & counterclockwise), the number of triangles node \(i\) belongs to is: \[\text{Triangles}(i) = \frac{p^3_{ii}}{2}\]

Walks of Length 3 (\(\mathbf{P}^3\)): Tracing Diagonal Cell \(p^3_{\text{C, C}}\)

  • Let’s compute the diagonal cell \(p^3_{\text{C, C}}\) (Node C’s triangles via 3-step walks):
    • Row 3 of \(\mathbf{P}^2\): \(\color{red}{\{2, 2, 5, 2, 3, 1\}}\)
    • Column 3 of \(\mathbf{P}\): \(\color{blue}{\{1, 1, 0, 1, 1, 1\}}\)

\[p^3_{\text{C, C}} = (\color{red}{2} \times \color{blue}{1}) + (\color{red}{2} \times \color{blue}{1}) + (\color{red}{5} \times \color{blue}{0}) + (\color{red}{2} \times \color{blue}{1}) + (\color{red}{3} \times \color{blue}{1}) + (\color{red}{1} \times \color{blue}{1}) = \mathbf{10}\]

  • The number of triangles containing Node C: \[\text{Triangles}(C) = \frac{10}{2} = \mathbf{5}\]

Application: Transitivity & Clustering Coefficient

Why count triangles?

  • High triangle count → cohesive, clustered network (friends of friends are friends).
  • Low triangle count → sparse structure (bridging, structural holes).
  • Clustering Coefficient = \(\frac{\text{triangles}(i)}{\text{possible triangles at } i}\) measures node’s embeddedness in cliques.

Summary: Matrix Multiplication in Networks

You now understand:

  1. Conformability ensures multiplications are mathematically defined.
  2. Non-commutativity means order determines both structure and meaning.
  3. \(\mathbf{A} \times \mathbf{A}^T\) counts common neighbors (off-diagonals) and degrees (diagonals).
  4. \(\mathbf{A}^2\) maps all walks of length 2 (including common neighbors and node degrees).
  5. \(\mathbf{A}^3\) counts walks of length 3 (revealing triangles and cycles).
  6. Higher powers reveal reachability, clustering, and diffusion potential.
